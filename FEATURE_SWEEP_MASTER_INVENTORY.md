## Classification Key

- `owner`: owner can perform or inspect a MenuList action in the app.
- `public`: customer/public route or public output.
- `read_only`: status/monitoring flow with no direct owner mutation.
- `export`: browser-local or download/share feature.
- `guarded_api`: mutation requires protected API or server authority.
- `internal`: platform/admin/operator surface.
- `separate`: sibling product surface, not MenuList feature scope.
- `blocked`: cannot be safely executed in this sweep.
- `docs_only`: docs exist but runtime is absent, deprecated, or handoff-only.
