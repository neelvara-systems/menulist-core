# Local Fonts

These files mirror the Google Fonts families previously loaded through `next/font/google`.

- `inter-latin-variable.woff2` covers Inter weights 100-900.
- `poppins-latin-*.woff2` covers the Poppins weights used by the Ant Design shell: 400, 500, 600, and 700.

Keep these local so Vercel builds do not depend on build-time requests to `fonts.googleapis.com`.
