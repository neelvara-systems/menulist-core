# Asset Reference Bank

This folder stores reference notes for Website Asset Operating System. Keep large raw files out of Git unless they are small, approved, and intentionally part of a public website surface.

## Allowed

- Short Markdown notes describing good and bad references.
- Links to repo-local screenshots under `__docs__/main-website/asset-production/`.
- Small cropped examples that are explicitly approved for reference use.
- Source-route notes and capture plans.

## Not Allowed

- Real customer screenshots without founder approval.
- Raw recordings, long videos, editor project files, or large exports.
- Private owner dashboard captures.
- Screenshots that expose tenant IDs, emails, phone numbers, API keys, or unreleased data.

## Reference Principle

Use references to constrain the next asset brief. Do not let references override product doctrine, source code, or the slot rules.
