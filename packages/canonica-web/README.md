# Canonica Web Helper

Internal unsupported helper source for Canonica runtime experiments.

Do not publish this package, document it as an end-user install option, or include it in public install guides. Canonica-supported client installs use the stable v1 browser contract:

- `https://canonica.app/widget/v1/canonica-widget.js`
- public `cn_*` widget key
- `window.CanonicaWidget`
- `setContext(context)` and `page(context)`
