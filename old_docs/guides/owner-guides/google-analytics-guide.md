# Google Analytics Guide for Restaurant Owners

This guide will help you set up and use Google Analytics (GA4) to track and analyze your menu website's performance.

## Setting Up Google Analytics

### 1. Create a Google Analytics Account
1. Go to [analytics.google.com](https://analytics.google.com)
2. Click "Start measuring"
3. Provide your account name (e.g., "My Restaurant Analytics")
4. Click "Next"

### 2. Create a Property
1. Enter your property name (e.g., "Menu Website")
2. Select your timezone and currency
3. Click "Next"
4. Fill in your business information
5. Click "Create"

### 3. Get Your Tracking ID
1. Click "Data Streams" in the left menu
2. Click "Add Stream" > "Web"
3. Enter your menu website URL
4. Click "Create Stream"
5. Copy your Measurement ID (starts with "G-")
6. Add this ID to your MenuListAI dashboard settings

## Viewing Your Analytics

### Quick Access
1. Go to [analytics.google.com](https://analytics.google.com)
2. Select your restaurant's property
3. You'll see the main dashboard with key metrics

### Key Reports for Restaurant Owners

#### 1. Real-Time Visitors
- Path: "Reports" > "Realtime"
- Shows:
  - Current active users
  - What they're viewing
  - Their location
  - Most viewed menu items

#### 2. Customer Location Data
- Path: "Reports" > "User" > "Demographics"
- Shows:
  - Cities/regions of your customers
  - Country distribution
  - Languages
  - Time zones

#### 3. Menu Performance
- Path: "Reports" > "Engagement" > "Events"
- Filter for events:
  - "menu_item_view": See most viewed items
  - "add_to_cart": Items added to cart
  - "purchase": Completed orders

#### 4. Customer Behavior
- Path: "Reports" > "Acquisition" > "Traffic acquisition"
- Shows how customers find your menu:
  - Direct visits
  - Search engines
  - Social media
  - Other websites

## Creating Custom Reports

### Popular Menu Items Report
1. Go to "Library" > "Create new report"
2. Add dimensions:
   - Item name
   - Category
3. Add metrics:
   - View count
   - Add to cart count
   - Purchase count

### Customer Location Report
1. Create new report
2. Add dimensions:
   - City
   - Country
3. Add metrics:
   - User count
   - Event count

## Setting Up Alerts

### Traffic Alerts
1. Go to "Admin" > "Alerts"
2. Click "Create alert"
3. Set up alerts for:
   - Sudden traffic increases
   - Unusual order patterns
   - New location visitors

### Performance Alerts
Set up alerts for:
- Low traffic periods
- High abandonment rates
- Successful promotions
