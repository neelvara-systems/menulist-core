# Owner Action Layer Website Boundary

## Public Website Decision

No dedicated public website page is needed for this feature.

The owner action layer is an in-app usability layer over existing MenuList capabilities. Public website copy should continue to describe the broader MenuList promise: one current customer source for menu, link, QR, hours, and feedback.

## Allowed Public Mention

If mentioned in existing owner-flow copy, keep it factual:

> MenuList shows the next useful setup or daily action inside the owner dashboard.

## Not Allowed

- Do not claim external-platform verification.
- Do not claim Google/Instagram/WhatsApp sync.
- Do not claim review monitoring.
- Do not claim social publishing.
- Do not claim holiday calendars.
- Do not claim automatic price optimization.

## Website Impact

No website route, navigation, sitemap, SEO metadata, public copy layer, or public tool output changes are required for this slice.
