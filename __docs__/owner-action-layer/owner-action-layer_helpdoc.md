# Owner Action Layer Help Doc

## Next Owner Action

The dashboard can show one next action for your business.

It may point to:

- menu
- hours
- customer link
- link placement
- private feedback
- today status
- staff sharing
- price updates

Open the action and complete it in the existing MenuList screen.

When the public information is stable, this card stays hidden. The dashboard says no action is needed instead of assigning routine work.

## Where It Appears

- Desktop dashboard
- Mobile dashboard

## What It Does Not Do

It does not change Google, Instagram, WhatsApp, reviews, or any external profile by itself.

External placements are owner-confirmed. MenuList keeps the confirmation visible so the same customer link stays in use.
