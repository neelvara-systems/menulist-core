# Global Accessibility Website Boundary

The MenuList website inherits browser zoom, visible keyboard focus, reduced-motion handling, image alternatives, and skip navigation from the shared app boundary.

Website page structure remains responsible for one meaningful primary-content landmark, semantic heading order, descriptive link text, form labels, error association, and current contrast. New website components should use native links and buttons before adding custom roles or keyboard handlers.

Public copy must not claim certification or complete accessibility based on this source pass alone.
