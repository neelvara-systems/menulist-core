# WhatsApp Action Link Check - Help Doc

**Status:** Implemented - V0 public browser-local checker
**Last Updated:** July 16, 2026
**Audience:** SMB owners and support

---

## What This Tool Checks

WhatsApp Action Link Check helps you see whether customers have a clear way to message your business.

It checks:

- whether a WhatsApp number or link was entered
- whether the click-to-chat format looks usable
- whether the first customer message is clear
- whether a menu, service, or customer link is attached
- whether reply timing or hours are clear
- whether there is a fallback action such as call, booking, or a public link

---

## What It Does Not Check

The tool does not:

- send a WhatsApp message
- open the WhatsApp link
- verify your WhatsApp account
- check whether the phone number belongs to your business
- open your website or customer link
- store the report unless you submit the follow-up form

---

## How To Use It

1. Enter your business name and city.
2. Enter your WhatsApp number or current WhatsApp link.
3. Add the menu, service, or customer link customers should see.
4. Write the first message customers should send.
5. Mark whether hours and fallback actions are clear.
6. Run the check.

The report will show what is ready, missing, unclear, and not checked.

---

## What To Do After The Report

If the report shows missing or unclear items, the best fix is usually to create one current customer link and add the WhatsApp action there.

That gives customers:

- one current menu or service page
- one visible WhatsApp action
- one fallback action
- clearer expectations before they message
