# WhatsApp Action Link Check - Website Copy

**Status:** Implemented - V0 public browser-local checker
**Last Updated:** July 1, 2026
**Audience:** Website/content maintainers

---

## Route

```txt
/tools/whatsapp-action-link-check
```

---

## Page Intent

The page should help an owner check a simple public action path:

```txt
Customer taps WhatsApp -> message intent is clear -> current customer link is attached -> fallback is available
```

The page must not imply a live WhatsApp integration.

---

## Hero Copy

Eyebrow:

> WhatsApp Action Link Check

Headline:

> Check if customers can message you in one tap.

Subtitle:

> Enter the WhatsApp action you already share. MenuList returns a short readiness report before you add it to one current customer link.

Trust chips:

- Format check only
- No message sent
- No link opened

---

## Form Copy

Form title:

> Check the WhatsApp action

Form subtitle:

> Use the number, link, and message prompt customers see today.

Fields:

- Business name
- City or locality
- WhatsApp number
- Existing WhatsApp link
- Current customer link
- Message intent
- Suggested first message

Self-report checks:

- Menu or service link is attached
- Reply timing or hours are clear
- Call, booking, or public-link fallback is shown

---

## Report Copy

Report title when empty:

> Report appears after the check

Boundary copy:

- Uses only entered fields
- Does not contact WhatsApp
- Stores nothing unless you submit the follow-up form

---

## SEO Boundary

Meta description should mention:

- WhatsApp action path
- one-tap message readiness
- current customer link

Meta description must not mention:

- account verification
- message delivery
- WhatsApp API
- AI ranking or citations
