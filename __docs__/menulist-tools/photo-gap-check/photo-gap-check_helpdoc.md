# Photo Gap Check - Help Documentation

**Status:** Public help draft
**Last Updated:** July 1, 2026

---

## Quick Summary

Photo Gap Check shows whether the basic visuals customers see are ready for one current customer link.

It checks only what you select. It does not upload, store, analyze, or inspect images.

---

## Getting Started

### What to prepare

- Business name
- City or locality
- Business type
- Current customer link, if one exists
- Whether a logo is visible
- Whether a cover image is visible
- Whether a storefront, location, team, or work photo is visible
- Whether product, menu item, service, or catalogue photos are visible
- Whether photos look current
- Whether the current public customer page shows images

---

## How To Run The Check

1. Open `/tools/photo-gap-check`.
2. Enter the business name and city.
3. Select the business type.
4. Add the current customer link if it exists.
5. Select the visual facts customers can already see.
6. Select **Run check**.

---

## How To Read The Report

The report uses four result labels:

- **Present** - the selected facts include this item
- **Missing** - the fact is not selected
- **Unclear** - the fact exists but may not be usable yet
- **Not checked** - V0 does not inspect that source

Each row includes evidence text. The evidence text says what was actually checked.

---

## Troubleshooting

### The report says visual basics are missing

Select at least one real visual asset customers can see, such as logo, cover image, storefront photo, product photo, or service photo.

### The report says public page images are missing

Add images to the current MenuList customer page or create one from the report action.

### The report says current customer link is missing

Add the current MenuList customer link or create one from the report action.

### The report says external verification is not checked

That is expected. V0 does not inspect Google, Instagram, websites, or social profiles.
