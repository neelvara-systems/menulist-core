## Problem Statement

Many SMBs have useful photos scattered across phones, social profiles, old posters, and old pages. Customers still need one current place where visual proof and business facts live together.

---

## Solution Statement

MenuList checks the visual facts the owner selects and returns a short report. The fix path is one current customer link with photos, menu or service details, hours, and actions in one place.

## How It Works

1. **Select visible facts** - Mark which visuals customers can already see.
2. **Read the report** - See present, missing, unclear, and not-checked rows with evidence text.
3. **Complete one link** - Move the fix into one current MenuList customer link.

## FAQ

**Q:** Does this upload images?
**A:** No. V0 uses selected facts only.

**Q:** Does this analyze photo quality?
**A:** No. It checks visual coverage, not image quality.

**Q:** Does this inspect Instagram or Google?
**A:** No. V0 does not inspect external platforms.

**Q:** Can this work for service businesses?
**A:** Yes. It checks public visual basics for restaurants, salons, clinics, shops, and local services.
