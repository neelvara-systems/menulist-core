## Route

`/tools/customer-question-coverage-check`

## Page Boundary

The page is a browser-local self-report tool. It does not fetch the submitted URL, read customer chats, call AI providers, or generate chatbot answers.

## Copy Direction

Use direct owner language:

- See whether customers can find answers before they message you.
- Check hours, menu, location, contact, pricing, and booking/ordering clarity.
- Copy or download the report.
- Ask MenuList for help only after explicit consent.
