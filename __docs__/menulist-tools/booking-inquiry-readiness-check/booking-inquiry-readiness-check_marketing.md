# Booking Inquiry Readiness Check - Marketing Notes

**Status:** Internal positioning
**Last Updated:** July 4, 2026

---

## Positioning

Booking Inquiry Readiness Check is a practical SMB tool:

> Check whether customers can clearly act from the public source they see.

It fits MenuList because the fix path is not a booking widget. The fix path is one current customer link with the action, contact, hours, location, and source in one place.

## Approved Language

- Check if customers can order, book, reserve, call, message, request a quote, or visit.
- See what is missing from the customer action path.
- Turn this into one current customer link.
- Keep action, hours, contact, and public source together.

## Avoid

- Booking automation claims.
- Calendar inspection claims.
- Payment or checkout verification claims.
- Google ranking, AI citation, or conversion promises.
- "We checked your booking provider" unless an approved adapter actually does that.

## Conversion Path

Free check -> gap report -> create/import MenuList customer link -> owner Business Health readiness -> V2 recurring/multi-location report only when needed.
