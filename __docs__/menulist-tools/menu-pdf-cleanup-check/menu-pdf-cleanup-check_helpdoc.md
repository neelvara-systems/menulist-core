# Menu PDF Cleanup Check - Help Doc

Menu PDF Cleanup Check shows whether an old PDF source is still useful for customers or should be replaced with one current MenuList customer link.

## What It Checks

- whether there is enough owner-entered information about the PDF
- whether the owner knows the PDF is current
- whether it is readable on a phone
- whether text can be selected or copied
- whether items, services, prices, rates, or packages are clear
- whether customers have a clear action path
- whether old QR or printed material still points to the PDF
- whether there is a current customer link

## What It Does Not Check

It does not upload your PDF, parse the PDF, run OCR, open the link, fetch the URL, inspect Google, scan a website, check QR images, call AI tools, scan search results, store the report, or update external platforms.

## How To Use It

1. Open `/tools/menu-pdf-cleanup-check`.
2. Enter where customers see the PDF today.
3. Add a PDF reference, filename, link, QR label, or note.
4. Select what is true about the PDF.
5. Run the check.
6. Use the report to replace the old PDF with one current MenuList customer link.

## Why MenuList Recommends This

PDFs are easy to share but hard to keep current. A customer link is easier to update when prices, availability, photos, hours, or actions change.
