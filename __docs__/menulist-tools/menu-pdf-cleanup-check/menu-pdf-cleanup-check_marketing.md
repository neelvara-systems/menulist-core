# Menu PDF Cleanup Check - Marketing Notes

**Audience:** Internal sales, founder-led outreach, partner conversations
**Public name:** Menu PDF Cleanup Check

## Positioning

Menu PDF Cleanup Check is a practical public truth tool:

> Old PDFs are where current menus go stale.

It helps owners see whether a PDF still works for customers and then routes them toward one current MenuList customer link.

## Good Outreach Angle

Use plain SMB language:

- "Is your PDF menu still current?"
- "Does your QR still point to an old PDF?"
- "Can customers read the PDF on a phone?"
- "Would one current customer link be easier to keep updated?"

## Avoid

- PDF parser
- OCR claim
- AI cleanup claim
- SEO audit
- automatic website scan
- external deletion or update claim
- guaranteed ranking

## Conversion Path

Free check -> gap report -> replace old PDF with MenuList customer link -> owner Business Health readiness -> paid recurring/multi-location/agency PDF cleanup reports only when needed.
