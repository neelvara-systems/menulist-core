## Problem Statement

Customers often see old or unclear hours across menus, posters, profiles, and shared links. A missing closed day or holiday note can make them call, message, or visit at the wrong time.

---

## Solution Statement

MenuList checks the hours facts the owner enters and returns a short report. The fix path is one current customer link with clear hours, menu or service details, and contact actions in one place.

---

## Feature Benefits

| Benefit | Description | Visual |
| --- | --- | --- |
| Regular hours are clear | Customers can see normal day and time information. | Form plus report row |
| Closed days are visible | Weekly closed days or open-daily status are not hidden. | Closed-day report row |
| Special hours have a place | Festival, seasonal, holiday, or temporary hours can be shown before customers arrive. | Holiday-hours row |
| Fallback action is present | Call, WhatsApp, booking, or contact fallback is visible when timing is uncertain. | Fallback row |
| One customer link is the fix | The report routes the owner into MenuList instead of scattered pages. | CTA to create customer link |

---

## How It Works

1. **Enter visible hours** - Add regular hours, closed days, special hours, location context, and current link.
2. **Read the report** - See present, missing, unclear, and not-checked rows with evidence text.
3. **Publish one link** - Move the fix into one current MenuList customer link.

---

## FAQ

**Q:** Does this check Google hours?
**A:** No. V0 checks only owner-entered fields.

**Q:** Does this update my hours anywhere?
**A:** No. It creates a local report and routes the fix path into MenuList.

**Q:** Are holiday calendars used?
**A:** No. V0 does not call holiday APIs or infer local holidays.

**Q:** Can this work for salons, clinics, and shops?
**A:** Yes. It checks public hours clarity for any SMB with customer-facing hours.
