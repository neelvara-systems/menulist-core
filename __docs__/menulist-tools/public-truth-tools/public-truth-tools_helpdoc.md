# Public Truth Tools - Help Documentation

**Status:** Active owner help for implemented tools and Business Health modules
**Last Updated:** July 16, 2026
**Audience:** Existing MenuList owners

---

## Quick Summary

Public Truth Tools show whether the public version of your business has the basics customers need: menu or service list, hours, location, contact, links, and photos.

Each tool gives a short status and a next step.

---

## Where This Appears

Public Truth Tools currently appear in:

- Business Health
- Official Business Page setup
- Share and QR flows
- WhatsApp/action-link setup
- Public Discovery
- MenuList public website tools

The paid Public Truth Monitor adds entitlement-gated manual saved history in desktop and mobile Business Health. Scheduled and multi-location monitoring are not active.

---

## Common Tool Types

### Public Source Status

Shows whether your customer-facing page has enough useful public facts.

### Menu Or Service List Status

Shows whether the current list has names, sections, prices where needed, and customer actions.

### QR Link Status

Shows whether the public link behind a QR code is still active.

### WhatsApp Action Status

Shows whether customers can use the expected message, order, booking, call, or contact action.

### Hours And Holiday Hours Status

Shows whether regular hours and special-day hours are clear enough for customers.

### Photo Status

Shows whether key public photos are missing.

---

## How To Use A Tool

1. Open the tool from the MenuList screen where it appears.
2. Read the status.
3. Select the available fix action.
4. Update the missing detail.
5. Save or publish from the normal MenuList flow.

Public report links are browser-local self-reports. They are not digitally signed MenuList records; confirm entered facts with the owner before changing business truth.

## Status Meanings

| Status | Meaning |
| --- | --- |
| Ready | The required public facts are present |
| Missing basics | One or more required fields are missing |
| Unclear | The source exists, but the public fact is not clear enough |
| Not checked | MenuList did not check that item |
| Manual review needed | The source needs a person to confirm it |

---

## Troubleshooting

### The tool says hours are missing

Add or update hours in the business settings or the Official Business Page screen.

### The tool says menu link is missing

Publish the current menu or select the customer link you want people to use.

### The tool says photo is missing

Add a business cover, logo, or gallery photo from the Official Business Page screen.

### The tool says manual review is needed

The source is not clear enough for an automatic result. Use the normal MenuList setup or contact support.

---

## Tips

- Keep one customer link in WhatsApp, Instagram, Google, and printed QR materials.
- Replace old PDFs when prices or services change.
- Keep hours and contact details in the same public source.
- Use the same public link everywhere customers ask.
