# Public Truth Tools - Marketing Notes

**Status:** Active internal messaging for implemented public tools and owner checks
**Last Updated:** July 16, 2026
**Audience:** Internal marketing, sales, founder

---

## 1. Elevator Pitch

Public Truth Tools show whether a business has clear public facts customers can trust: current menu or service list, hours, location, contact, links, photos, and customer actions.

---

## 2. Positioning

This is not "AI SEO."

This is:

```txt
public business facts made clear enough to use
```

The tools make the problem visible, then route the fix back to MenuList.

---

## 3. Product Story

Many SMBs already have a website, Google profile, Instagram page, WhatsApp number, PDF, QR code, and old menu images. The problem is not that they have no online presence. The problem is that customers do not know which public source is current.

Public Truth Tools give a simple report:

- what is clear
- what is missing
- what is unclear
- what MenuList can turn into one current customer link

---

## 4. Differentiation

| Alternative | What it does | MenuList difference |

## 8. Objection Handling

| Objection | Response |
| --- | --- |
| "Is this SEO?" | It checks whether public facts are clear. Search is one reader, not the product promise. |
| "Is this like CrowdReply?" | No. CrowdReply influences third-party conversations. MenuList owns the source facts. |
| "Can it fix Google?" | It can prepare the correct source and link. External platforms decide how they use it. |
| "Can it post for me?" | No. Public Truth Tools do not post. They show gaps and route corrections. |
| "Is this another dashboard?" | No. Each tool returns a short report and a fix path. |
