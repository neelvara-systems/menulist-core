## Page Copy Rules

Copy must stay practical and owner-facing:

- no login needed
- browser-local
- checked owner-entered fields only
- no external pages were opened
- no file was stored
- no AI/search check was performed

Each page should make the asset visible after generation, then offer the next MenuList fix path.

- `/tools`
- desktop header Resources menu
