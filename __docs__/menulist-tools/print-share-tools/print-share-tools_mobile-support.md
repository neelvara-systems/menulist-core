# Print & Share Tools - Mobile Support

**Last Updated:** July 16, 2026

---

## Mobile Scope

V0 is public responsive website UI with browser-local generation. It is not an owner mobile shell feature yet.

The public pages must work on phone screens because many SMB owners will use WhatsApp, screenshots, and mobile sharing first.

---

## Requirements

- form fields must be readable on mobile
- action buttons must remain at least 44px tall
- generated preview must not overflow the viewport
- route switcher links must wrap without overlap
- PNG/PDF/print/share buttons must remain tappable
- no desktop-only hover dependency
- no login wall

---

## Future Owner Mobile V1

If this becomes an owner-side tool, it should appear through existing owner mobile paths:

- Share
- QR/share readiness
- Official Business Page readiness
- Business Health

Do not create a separate mobile dashboard for V1.
