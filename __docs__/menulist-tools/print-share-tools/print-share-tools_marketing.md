# Print & Share Tools - Marketing Notes

**Last Updated:** July 16, 2026

---

## Positioning

MenuList Print & Share Tools help SMB owners make simple public assets around one current customer link.

Use this framing:

```txt
Make the small asset customers actually scan or share.
Keep the link current.
Use MenuList when you are ready to make that link the source of truth.
```

---

## Allowed Language

- free public QR poster maker
- browser-local asset maker
- make a WhatsApp Status image
- make a holiday-hours poster
- make a customer link card
- make an ethical feedback QR card
- no login needed
- nothing is stored unless the owner later asks for follow-up through an approved flow

---

## Avoid

Do not market these as:

- AI visibility tools
- ranking tools
- review generation tools
- Google profile updaters
- WhatsApp automation
- social posting tools
- full design editor access
- proof that a QR code was scanned or placed correctly

---

## Conversion Path

The natural next step is not "subscribe now." It is:

```txt
Create one current customer link
```

Paid packaging can come later for seasonal packs, multi-location consistency, agency exports, saved history, and managed setup work.
