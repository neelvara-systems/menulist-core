# Print & Share Tools - Help Doc

**Last Updated:** July 16, 2026

---

## What This Does

Print & Share Tools let an owner make a simple QR-based asset from public, owner-entered information.

Examples:

- poster for a menu link
- WhatsApp Status image
- holiday-hours poster
- counter card
- feedback QR card

---

## What The Tool Checks

The report checks whether:

- business name was entered
- customer link uses a public HTTPS URL
- asset message is clear enough to print or share
- customer action is clear
- owner confirmed the asset is ready to print/share
- feedback use is ethical where relevant

The URL format check is browser-local. The page is not opened. Local, private, insecure, and credentialed links are not accepted for customer QR assets.

---

## What The Tool Does Not Do

It does not:

- require a MenuList login
- upload files
- store generated files
- save reports
- update Google, WhatsApp, Instagram, Facebook, review sites, or directories
- inspect search or AI answers
- generate review text
- send messages

---

## Best Next Step

If the report shows missing basics, create one current MenuList customer link and use that link in the generated asset.

If the copy button does not work because the browser blocks clipboard access, use the visible public report link field or open the public report directly.
