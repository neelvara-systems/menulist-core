# Google Profile Basics Checklist - Marketing Notes

**Last Updated:** July 4, 2026

**Public name:** Google Profile Basics Checklist

## Positioning

Use this as a practical setup checklist:

> Check whether the Google profile facts you maintain are ready for customers and point to one current customer link.

## Why SMB Owners Understand It

Owners already know customers find them on Google. The gap is usually not awareness; it is whether the profile points to the current menu, service list, booking path, photos, hours, and contact source.

## Use

- restaurants with old menu links
- salons and clinics with service/booking links
- repair/rental/service businesses with enquiry links
- agencies preparing profile setup handoff
- multi-location owners checking handoff readiness

## Avoid

- "rank higher"
- "Google verified"
- "we updated Google"
- "we checked your Google profile"
- "AI visibility"
- "review growth"
- "listing management"

## Conversion Path

Free checklist -> gap report -> create one current MenuList customer link -> owner Google handoff readiness -> paid recurring/multi-location/agency reports only when needed.
