# Customer FAQ Reply Pack - Help Doc

**Last Updated:** July 4, 2026

## What It Does

Customer FAQ Reply Pack creates reusable customer answer text from the questions and facts you enter.

It can prepare answers for:

- what you sell or serve
- when you are open
- prices or quote path
- where you are and how to contact you
- how to order, book, request a quote, or visit
- availability notes
- fallback questions that need confirmation

## What It Does Not Do

The tool does not read customer conversations, create a chatbot, configure automation, send messages, fetch links, store the report, or update any external profile.

## How To Use It

1. Enter the questions customers repeatedly ask.
2. Enter the business facts answers should use.
3. Create the FAQ pack.
4. Copy the answers you need.
5. Use the next action to create one current customer link in MenuList.

## Follow-Up Form

The report is local unless you choose to send it to MenuList. If you send it, MenuList receives the report through the existing public contact route and uses it to respond to the setup request.
