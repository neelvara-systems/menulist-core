# Customer FAQ Reply Pack - Marketing Notes

**Status:** Internal positioning for V0 public tool
**Last Updated:** July 4, 2026

---

## Positioning

Customer FAQ Reply Pack helps an SMB owner turn repeated customer questions into consistent answers. It prepares text the owner can use on a website FAQ, staff note, social reply, or setup handoff.

Use this language:

- Create reusable FAQ answers from your customer questions.
- Keep menu, hours, price, location, and action answers consistent.
- Copy the answers before creating an account.

Avoid this language:

- chatbot
- inbox automation
- auto-resolve support
- message sender
- AI answer bot
- guaranteed conversions
- ranking, SEO, AI citation, or visibility promise

## Conversion Path

Free check -> FAQ pack -> shareable report -> create/import MenuList customer link -> optional setup help.

## SMB Value

The useful moment is the owner seeing the answers they can use today and the missing facts that should live on one current customer link.
