# Menu Readability Check - Help Doc

**Status:** Implemented - V0 public route
**Last Updated:** July 4, 2026
**Audience:** Owners and support

---

## What It Does

Menu Readability Check helps you check whether customers can understand the menu, service list, catalog, rate card, package list, or price list you already share.

It shows whether the pasted text has clear sections, items or services, prices, helpful details, and a next action.

---

## How To Use It

1. Copy the current menu or service text you send to customers.
2. Paste it into Menu Readability Check.
3. Add the public link you share today, if you have one.
4. Select what customers can already see.
5. Run the check.

---

## What It Checks

- Whether enough source text was pasted.
- Whether sections or categories are clear.
- Whether concrete items or services are listed.
- Whether prices or rates are visible when needed.
- Whether descriptions or details help customers choose.
- Whether customers can see how to order, book, call, or message.
- Whether a public customer link is present.

---

## What It Does Not Check

- It does not upload files.
- It does not read PDFs or images.
- It does not open the public link.
- It does not rewrite the menu or service list.
- It does not check Google, Instagram, WhatsApp, or other profiles.
- It does not promise search ranking, AI visibility, or more orders.

---

## What To Do With The Report

If the report says the source is missing basics or unclear, use MenuList to turn the current text into one customer link with clearer categories, prices, details, and actions.

---

## Data And Privacy

The report runs in your browser. MenuList does not store the report unless you submit the follow-up form and agree to be contacted.
