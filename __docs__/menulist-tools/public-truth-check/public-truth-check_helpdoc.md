# Public Truth Check - Help Documentation

**Status:** Implemented - public self-report route
**Last Updated:** July 4, 2026
**Audience:** SMB owners

---

## Quick Summary

Public Truth Check shows whether customers can find the basic facts about your business from one clear source.

It checks menu or service source, hours, location, contact, customer links, and photos where available.

---

## What You Need

You can use any one of these:

- current menu photo or PDF
- service list
- package list
- rate card
- catalog
- public business link
- MenuList customer link

---

## How To Run The Check

1. Open Public Truth Check.
2. Add your business name.
3. Add your city or area.
4. Add your current menu, service list, or public link.
5. Run the check.
6. Read the report.
7. Use the next action shown in the report.

---

## What The Report Shows

| Status | Meaning |
| --- | --- |
| Present | This fact is available |
| Missing | This fact was not found in the source |
| Unclear | The fact exists but is not clear enough |
| Not checked | The tool did not check this fact |
| Not applicable | Your business type does not need this fact |

---

## Common Results

### Menu or service source is missing

Add your current menu, service list, catalog, rate card, or package list.

### Hours are missing

Add opening hours before using the customer link widely.

### Contact is missing

Add phone, WhatsApp, email, or the customer action you want people to use.

### Public link is missing

Create one current customer link in MenuList.

### Photo is missing

Add a logo, cover photo, or business photo from the Official Business Page screen.

---

## What This Does Not Do

Public Truth Check does not:

- post to Google, Instagram, Reddit, Quora, or Facebook
- guarantee ranking
- guarantee AI answers
- change menu prices or hours automatically
- use private pages or login-only sources

---

## Tips

- Use one current link in WhatsApp, Instagram, Google, QR codes, and printed material.
- Replace old menu PDFs when prices change.
- Keep hours and contact details in the same public source.
- For service businesses, include starting prices or clear inquiry actions.
