# Public Truth Check - Marketing Notes

**Status:** Implemented - public self-report route
**Last Updated:** June 30, 2026
**Audience:** Internal marketing, sales, founder

---

## Elevator Pitch

Public Truth Check shows whether a business has one clear public source for customers: menu or service list, prices, hours, location, contact, and links.

---

## Core Narrative

Most SMBs are not invisible. They are scattered.

Their current facts may live across:

- a PDF
- Instagram highlights
- Google profile
- WhatsApp messages
- an old website page
- a QR code
- a printed menu
- a staff-shared image

Public Truth Check turns that scattered state into a simple report and a fix path.

---

## What Makes It MenuList

This tool is not a generic audit.

It is useful because MenuList can fix the gap:

```txt
unclear public source -> owner-approved MenuList source -> one current customer link
```

## Landing Page Copy Hooks

### Hero

Check if your public business info is clear.

### Subheading

MenuList checks the basics customers need: menu or service list, hours, location, contact, and links.

- Turn one current source into one customer link.
- Use it for menus, service lists, packages, catalogs, and rate cards.
- No ranking promises. Just a clearer source.

---

## Use Cases

### Restaurant

Old menu images are still circulating. The check shows that hours and prices are unclear, then routes the owner to create one current menu link.

### Salon

Services and starting prices are split across Instagram and WhatsApp. The check shows missing service-list structure and suggests one current service page.

### Local Service Business

A rate card PDF exists, but customers cannot find the latest version. The check routes the owner to create one public list with inquiry actions.

### Agency

The agency runs the check before website or Instagram work. The report becomes the source-cleanup brief.

## Pricing/Packaging Story

Public Truth Check should start as a free tool.

Paid value can be introduced only when there is recurring value:

- saved reports
- multi-location checks
- recurring public source status
- agency exports
- sampled AI/search readability checks with strict claim boundaries

Do not charge for the first basic report unless acquisition data proves a better setup flow.
