# Shareable Tool Reports - Website Copy Rules

**Status:** Public copy guidance
**Last Updated:** July 5, 2026

---

## Public Page

Route: `/tools/reports`

Approved copy themes:

- public report link
- checked facts
- evidence text
- clear limits
- next MenuList action

Avoid:

- scan
- crawl
- rank
- AI visibility
- guaranteed citation
- external platform update

---

## Required Boundary Copy

Each report must include:

- what was checked
- what was not checked
- evidence row text
- no ranking or citation promise
- no external update claim

If the report came from owner-entered fields, say that directly.

---

## Share Button Copy

Preferred source-tool button:

```txt
Copy public report link
```

Preferred viewer buttons:

```txt
Copy link
Copy report
Download report
```

Preferred viewer follow-up CTA:

```txt
Send report for follow-up
```

Do not say the report was emailed or delivered automatically unless a delivery provider exists in the implementation. The current viewer submits a consented follow-up request to MenuList.

The follow-up request can be described as sending the report summary to MenuList. Do not describe it as creating saved history, a private report dashboard, or a recurring monitor.
