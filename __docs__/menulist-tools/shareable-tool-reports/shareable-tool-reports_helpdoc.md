# Shareable Tool Reports - Help Doc

**Status:** Help article draft
**Last Updated:** July 5, 2026

---

## What Is A MenuList Tool Report?

A MenuList Tool Report is the result of a free public check.

It shows:

- the result
- what was checked
- what was not checked
- the evidence for each row
- the next MenuList step

You can open a shared report without logging in.

---

## Does MenuList Store The Report?

For the first public version, no.

The report details are carried inside the shared link. MenuList does not create a Firestore report record when you copy or open the link.

If you submit a follow-up form from a source tool or from the shared report page, that separate form sends only after you give consent and the security check passes. MenuList stores it as a public contact enquiry for follow-up, including the tool name/status and a short bounded report summary, not as a saved report record.

---

## Can The Report Check Google, Instagram, Or Search?

Only if the specific tool says it did.

Most V0 public tools use owner-entered fields only. If a tool did not open or fetch an external profile, the report will say that.
