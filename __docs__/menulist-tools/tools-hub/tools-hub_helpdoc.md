# Tools Hub - Help Doc

**Last Updated:** July 9, 2026

## What is MenuList Tools?

MenuList Tools is a set of free checks that help you see whether your public business information is clear for customers.

The tools can help you check things like:

- your customer link
- your menu or service list
- prices and availability
- QR links
- WhatsApp actions
- hours
- photos and basic identity

## Does the hub check my website?

No. The hub only helps you choose a tool.

Each free V0 tool explains what it checks. Most public tools use only the details you type or paste into the page.

## Does MenuList promise rankings or AI citations?

No. The tools are about public business truth and customer clarity. They do not promise rankings, citations, or updates on external platforms.

## What should I do after a check?

Use the report to create or clean up one current MenuList customer link. That link can become the source customers open from QR, WhatsApp, Google profile handoff, social bios, print, and public pages.
