# Tools Hub - Mobile Support

**Last Updated:** July 4, 2026

## Scope

The public hub is responsive website UI only.

It does not add a mobile owner-PWA screen, MobileShell route, mobile DAL hook, or mobile-specific data contract.

## Mobile Behavior

- Cards collapse into a single-column list.
- CTAs stretch to full width on narrow screens.
- Tool links remain standard website links.
- Header mobile resources accordion includes MenuList Tools when the visitor is on `/tools` or a tool route.

## V1 Owner Surface

Logged-in owner checks continue to belong in existing owner surfaces:

- Business Health
- Public Discovery
- Official Business Page readiness
- QR/share readiness
- mobile owner Business Health surfaces

The hub should not become a separate owner dashboard.
