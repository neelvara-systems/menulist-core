# Price Availability Gap Check - Help Doc

Price Availability Gap Check shows whether customers can understand prices and availability from the public source you already share.

## What It Checks

- whether enough source text was provided
- whether prices, rates, costs, fees, starting prices, or quote paths are clear
- whether currency, unit, serving, or per-person context is clear
- whether variants, packages, combos, or options have clear prices when relevant
- whether availability, unavailable, sold-out, seasonal, or limited items are clear
- whether customers have a current public link

## What It Does Not Check

It does not open your website, inspect Google, connect to a POS, check live inventory, inspect ordering providers, call AI tools, scan search results, or update external platforms.

## How To Use It

1. Open `/tools/price-availability-gap-check`.
2. Paste the menu, service, catalog, package, or price-list text customers currently see.
3. Select how prices and availability are shown.
4. Add your current customer link if you have one.
5. Run the check.
6. Use the report to fix the source or create one current MenuList customer link.

## Why MenuList Recommends This

Customers should be able to see what is offered, what it costs, what is available, and how to act without asking the same basic questions repeatedly.
