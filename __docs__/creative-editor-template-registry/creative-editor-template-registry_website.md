# Creative Editor Template Registry - Website Boundary

**Status:** No standalone public page  
**Last Updated:** June 15, 2026

## Decision

This is an infrastructure capability inside MenuList Assets. It should not become a public feature page by itself.

## Where It Can Appear

- Assets/help copy can mention saved print designs.
- Feature pages can say owners can reuse customized print layouts.
- Support content can explain Saved designs.

## Copy Guardrails

- Use calm owner-readable language.
- Do not say "AI-powered".
- Do not promise a template marketplace.
- Do not imply automatic external printing fulfillment.

## Example Copy

"Save a print design as your own template, then reuse it the next time you need a table card, entrance poster, or feedback QR."
