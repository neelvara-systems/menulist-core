# Help: Save and Reuse a Print Asset Design

**Audience:** MenuList owners  
**Last Updated:** June 15, 2026

## What You Can Do

You can save a print asset design after editing it, then reuse it later for the same type of asset.

## Save a Template

1. Open **Assets**.
2. Choose an asset type.
3. Choose a MenuList template.
4. Select **Customize in editor**.
5. Edit the text, colors, and layout.
6. Select **Save as template**.

The design appears under **Saved designs** for that asset type.

## Reuse a Template

1. Open **Assets**.
2. Choose the same asset type.
3. Open **Saved designs**.
4. Select your saved template.

MenuList refreshes the QR link from the current selected project before you download.

## Important Notes

- The QR link is protected so printed assets keep working.
- Saving a template is separate from downloading a file.
- If you only preview or download a MenuList template, no saved template is created.
