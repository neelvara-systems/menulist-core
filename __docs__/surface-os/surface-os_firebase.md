# SurfaceOS - Firebase Boundary

**Runtime status:** No SurfaceOS Firebase resources exist.
**Current runtime cost:** Zero.
**Last verified:** July 17, 2026

SurfaceOS has no:

- Firebase project or alias;
- client or Admin Firebase configuration;
- Firestore collection constant, rule namespace, composite index, TTL policy,
  listener, query, or write;
- Storage path or rule;
- Cloud Functions package, trigger, scheduler, task queue, webhook, secret, or
  provider call; or
- billing, credit, transaction, notification, or operations ledger.

The reserved `SF` product code is accepted only as optional source provenance
on existing bounded feedback records. It does not grant access to a SurfaceOS
collection and creates no operation by itself.

Do not put future SurfaceOS data in an existing product project. A future
persistence proposal must first decide whether Firebase is appropriate, then
document isolation, regional placement, retention, indexes, read/write budgets,
provider costs, deployment targets, and rollback.
