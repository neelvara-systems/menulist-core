# SurfaceOS - Reserved Concept Specification

**Status:** Planning only; implementation not approved
**Last verified:** July 17, 2026

## Purpose

This specification governs only the current reservation boundary. SurfaceOS is
a possible future product concerned with representation across third-party
discovery channels. That sentence is a concept, not a feature promise.

## Current Acceptance Criteria

- `SF` remains a stable reserved product code.
- Reserved domains cannot be claimed as MenuList custom domains.
- The product-site placeholder remains disabled.
- No local, public, owner, mobile, or API route renders SurfaceOS.
- No active deployment, Firebase, provider, billing, or environment contract
  exists.
- Existing MenuList, Answerlattice, CampaignCue, SignalDesk, GrowthOS,
  KitStamp, MyCodex, and Neelvara behavior remains unchanged.
- Public copy and help content do not advertise the concept.

## Current Non-Goals

The repository does not currently approve:

- listing or profile synchronization;
- Google, Apple, directory, review, or other provider adapters;
- drift detection, policy engines, automated replies, or analytics;
- a SurfaceOS owner dashboard or mobile shell;
- imports from or write-back to MenuList;
- any database, queue, scheduler, webhook, secret, credit, or subscription;
- a target customer, pricing model, launch order, technology stack, or parent
  brand; or
- the architecture described in archived research.

## Future Decision Boundary

A later product proposal must be reviewed against then-current code, provider
terms, customer evidence, security rules, cost limits, and product doctrine.
Archived planning cannot be treated as implementation authority.
