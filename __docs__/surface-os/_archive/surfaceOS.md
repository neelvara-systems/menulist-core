State Definitions

Sync event created but not yet processed.

VALIDATING
Adapter validation running.

QUEUED
Waiting for rate limit window or worker allocation.

SYNCING
Adapter.sync() executing.

Lock must be enforced.

SUCCESS
lastSyncedVersion updated

syncHash updated

completedAt timestamp set

retryCount reset

Terminal state.

FAILED
errorCode stored

errorMessage stored

retryCount incremented

failure classified

May transition to PENDING again only if retryable.

No infinite loops.
