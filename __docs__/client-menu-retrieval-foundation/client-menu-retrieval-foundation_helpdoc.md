# Client Menu Retrieval Foundation Helpdoc

## What Customers Experience

Customers can search the menu with common spelling variations. For example, a customer looking for an item may still find it even if they type a slightly different spelling.

If the connection is unavailable, the menu shows a clear offline screen and asks the customer to reconnect. It does not show an old saved copy of the menu.

## What Owners Need To Do

No action needed.

Menu search uses the menu information the owner has already published.

## Why Offline Menus Are Not Shown

Menu prices, availability, and items can change. Showing an old saved copy could be wrong. MenuList shows the latest live menu when the connection is available.
