# Client Menu Retrieval Foundation Marketing Notes

## Internal Positioning

This is not a visual redesign. It strengthens MenuList as a customer-facing business truth layer by reducing retrieval friction and protecting freshness trust.

## Sales-Safe Language

- Customers can find items faster.
- Search handles common spelling differences.
- Public menus stay focused on current information.
- Weak network states are handled clearly.

## Avoid

- AI-powered search.
- Offline menu claims.
- Guaranteed discovery claims.
- Verified data claims without verification infrastructure.
