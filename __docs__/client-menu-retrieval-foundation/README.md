## Scope

This feature strengthens three existing customer-menu foundations:

- fuzzy and transliteration-aware public menu search;
- visible/schema alignment for menu freshness and item/category truth;
- low-network behavior that never serves stale cached menu content.

AI retrieval APIs and AI chat/search surfaces are intentionally out of scope until the base search and truth contracts are stable.
