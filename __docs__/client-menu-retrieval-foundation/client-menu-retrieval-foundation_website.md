# Client Menu Retrieval Foundation Website Notes

## Public Website Claim Boundary

Allowed public claim:

> Customers can search published menus even with common spelling differences.

Allowed public claim:

> Menus show the latest live information when the connection is available.

Not allowed:

- AI-powered search.
- Verified menu claims without actual verification workflow.
- Offline menu access claims.
- Any claim that cached menu data is available without reconnecting.

## Website Update Need

No immediate website copy change is required unless a public feature section is added for menu search or customer app reliability.
