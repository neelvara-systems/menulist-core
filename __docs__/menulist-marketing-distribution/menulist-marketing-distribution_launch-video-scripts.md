## Purpose

This document provides launch video scripts for the broad-SMB demo universe.

It covers:

- three 10-15 second vertical clips;
- one 60-90 second walkthrough;
- claim boundaries and visual requirements.

No video files are created in this pass.

---

## Script Rules

1. Show the transformation quickly: scattered source -> MenuList public link -> customer surface.
2. Use demo businesses only unless real customers give permission.
3. Do not promise revenue, ranking, Google refresh, AI citations, traffic growth, or automatic external-platform updates.
4. Do not claim MenuList replaces booking, POS, delivery, ecommerce, or social media.
5. Keep on-screen text short and mobile-readable.
6. Use `Sample business. Demo data only.` where the asset could look like customer proof.

**Format:** 1080 x 1920

Old PDFs and menu screenshots drift. MenuList gives the business one owner-approved customer link.

## 60-90 Second Walkthrough

**Working title:** One Official Customer Link  
**Format:** Horizontal first, can be cropped into vertical sections  
**Demos:** Local Table Cafe, Glow & Blade Studio, Spark Auto Detailing, Urban Glow Group  
**Goal:** Product Hunt, website, founder posts, demo calls.

### Script

| Time | Visual | Voiceover / narration |
| --- | --- | --- |
| 0-6s | Fast montage: old PDF, WhatsApp screenshot, Instagram highlight, counter poster | Small businesses update their real menu or service list, but customers keep finding old copies. |
| 6-14s | Local Table Cafe source list beside public menu | A cafe changes prices. The QR code, WhatsApp menu, and old PDF can all drift. |
| 14-22s | Glow & Blade Studio source list beside public service list | A salon changes a service rate. Instagram highlights and staff screenshots may still show the old version. |
| 22-30s | Spark Auto Detailing rate card beside public package page | A local service updates packages. Customers still ask for rates because the list is scattered. |
| 30-42s | `/create-menu` broad source copy and source upload/list input | MenuList starts from the list the business already uses: a menu, service list, package list, catalog, or price list. |
| 42-54s | Prepared public customer link and owner review proof | The owner reviews the customer-facing version before publishing. |
| 54-66s | QR, WhatsApp, Instagram, Google/menu link, print files, saved shortcut | The same approved link can support the places customers already look. |
| 66-78s | Urban Glow Group multi-location concept | For growing businesses, one central list can still allow branch-level details. |
| 78-90s | MenuList logo, CTA, sample label | MenuList gives customer-facing SMBs one official customer link for the current list customers need to see. |

### On-Screen Text Beats

1. Old copies drift.
2. Start from the current list.
3. Owner reviews before publishing.
4. One official customer link.
5. QR, WhatsApp, Instagram, Google, print.
6. Menus, services, packages, catalogs, prices.
7. Create customer link.

### CTA

Recommended:

```text
Create customer link
```

Alternate:

```text
Start with your current list
```

## Production Checklist

Before recording:

- source-before visuals are ready;
- routed product screenshots or approved mockups are ready;
- demo/sample label is included where needed;
- no real customer data appears;
- all public claims match MenuList claim boundaries;
- mobile text is readable at 390px and 320px widths;
- founder approves names and category mix.
