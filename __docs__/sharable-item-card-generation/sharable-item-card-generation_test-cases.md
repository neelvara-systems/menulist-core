# Sharable Item Card Generation Test Cases

- Desktop edit item shows Share card and Download card for existing items.
- Mobile edit item sheet shows Share card and Download card for existing items.
- Add item mode does not show card actions before the item exists.
- Public PDP does not show Copy Link or Download Card.
- Card generation succeeds with item image.
- Card generation succeeds without item image.
- Web Share fallback downloads a PNG when file sharing is unavailable.
- No `/api/og/item` or `/api/item-card` request is made.
