## Problem Statement

Running multiple locations means managing multiple menus. Prices drift, items disappear from one location, names change without HQ knowing. You spend mental energy wondering "Is every store showing the same menu?"

## Solution Statement

MenuList's multi-outlet system lets you maintain one master menu. Update it once, and linked stores receive the saved changes through the outlet save/cache path. Stores can adjust local prices or mark items as unavailable — but the core menu stays consistent.

## Feature Benefits

### 1. Master Menu, Controlled Updates

Change a price on the master menu → linked stores receive the saved update through the current sync/cache path. Customer menus can take up to 60 seconds to refresh.

> **Visual:** Master menu being edited → linked outlet menus receiving the saved update

### 2. Controlled Local Flexibility

Each store can adjust prices for their market or mark items as temporarily unavailable — without affecting the master menu or other stores.

> **Visual:** Master: "Burger ₹350" → Store A: "₹350" → Store B: "₹399 (airport pricing)"

### 3. Brand Protection

Core menu items, names, and descriptions stay locked. No store manager can rename "Signature Butter Chicken" to "Chicken Special" without HQ approval.

> **Visual:** Lock icon on key menu items with "HQ Controlled" badge

### 4. Zero Daily Effort

Once set up, you never think about menu consistency again. The system handles inheritance, merging, and sync automatically.

### 5. Add Outlets in Seconds

Open the Locations page, click "Add Outlet", name it, done. Mobile owners can use More → Locations for the same flow. The new store gets all your master menus automatically. Billing adjusts to include the new location — no plan changes needed.

> **Visual:** "Add Outlet" button → outlet name input → billing summary showing per-store cost

### 6. One Dashboard, Every Location

The Chain Control Panel shows all your stores in one place. See which outlets are active, view billing per store, and switch between locations with one click.

> **Visual:** Locations table with HQ star badge, outlet rows with status badges, "View" buttons

## How It Works

1. **Create Master Menu** — Build your core menu at HQ
2. **Add Outlets** — Click "Add Outlet" from the Locations page. Menus are copied automatically.
3. **Local Adjustments** — Each store can adjust prices or availability
4. **Automatic Sync** — Saved master changes flow to linked stores through the current sync/cache path; customer menus can take up to 60 seconds to refresh
5. **Manage from HQ** — Switch between stores, view billing, control outlet permissions
