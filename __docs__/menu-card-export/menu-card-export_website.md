## Problem Statement

Printed menus, service lists, and catalog sheets go stale fast. A price changes online, but the paper file still shows the old price.

Owners should not rebuild menu cards every time the menu changes.

---

## Solution Statement

MenuList creates print-ready files from the current menu, service list, or catalog. The printed file can include a QR code back to the latest live version, so customers always have a path to the current version.

---

## Feature Benefits

### One Menu, More Places

Your QR page, official page, and printed file come from the same source.

## How It Works

1. **Choose the job** — Home print, WhatsApp PDF, or print-shop packet.
2. **Preview the pages** — Check page count and warnings before export.
3. **Create the file** — Download or share the PDF/packet.

## FAQ

**Q:** Is this a design editor?
**A:** No. MenuList handles the layout so the menu card stays consistent.

**Q:** Can the PDF include a QR code?
**A:** Yes. The QR code opens the latest live menu.

**Q:** Can I use this from my phone?
**A:** Yes. The export flow works from desktop and mobile.

**Q:** Can I send it to a print shop?
**A:** Yes. The print-shop packet is designed for that handoff when enabled.

**Q:** Does the printed menu update automatically?
**A:** Printed paper cannot update itself. MenuList shows when an older export was created before the latest menu change.
