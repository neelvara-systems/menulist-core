# Finance Operating System Mobile Support

FinanceOS has no product mobile screen or PWA surface. The founder may capture evidence on a phone. Routine evidence must be redacted and transferred to the private local store through an owner-controlled method. An exact business/KYC source may be transferred only after explicit founder authorization and must land directly in a permission-locked `Restricted-Originals/` area with an indexed hash; authentication/payment-authorization secrets remain prohibited.

Do not add MenuList or Answerlattice mobile UI, notifications, routes, or Firebase writes for FinanceOS without a separate product-boundary decision.
