# MenuList Activation Concierge - Marketing Boundary

**Status:** Local source complete; internal name only

Activation Concierge is not a public product claim. Owner-facing language is **Starter sharing steps** or **Menu setup**.

## Accurate message

MenuList helps the owner place the official link through existing sharing tools and records two distinct setup actions. In-product actions are MenuList-recorded; external placements are owner-confirmed.

## Do not claim

- that the link is actually used by customers;
- verified placement on Google, Apple, Bing, Instagram, or WhatsApp;
- traffic, scan, lead, ranking, or sales outcomes;
- automatic external posting;
- a public proof/case-study engine;
- a separate concierge route or service.
