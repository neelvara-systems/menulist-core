# SMB Public Business Truth — Full Analysis

**Version:** 1.0 | **Date:** February 22, 2026  
**Sources:** Gemini, Perplexity, Grok, ChatGPT + Cascade Web Research

---

## 1. Methodology

Five independent sources ran the same research prompt. Cascade did parallel web searches. All cross-checked against MenuList SSOT.

| Source | Strength | Weakness |
|--------|----------|----------|
| Gemini | Academic framing, trust psychology | Verbose |
| Perplexity | Highest citations, 2024-25 data | Aggregator-focused |
| Grok | Concise, realistic severity ranking | Fewer citations |
| ChatGPT | Clean taxonomy, signal filtering | No web search |
| Cascade | Real-time 2025 validation | Search-limited |

---

## 2. Perfect Convergence (All 5 Agree)

1. **No canonical public source of truth exists** — Every surface maintains its own copy. Drift is inevitable.
2. **Manual middleware** — Owner = human sync engine. 30-60 min/day. Fails under stress.
3. **Price mismatch = highest trust damage** — Customers see deception, not system error. Gemini: "1% discrepancy → 3-5% rating decline."
4. **Google = most reputation-sensitive surface** — Edits overridden, 24-48h propagation delay.
5. **Current software solves internal ops, not public truth** — POS/delivery/website are silos.
6. **Problems universal, amplified by market** — India: aggregators+WhatsApp. US: Google+QR backlash. Europe: language. SEA: messaging.

---

## 3. Strong Convergence (4 of 5)

- **Real-time 86ing** — Daily stockouts not reflected publicly. Highest frequency.
- **WhatsApp parallel reality** — Static images diverge in hours (India/SEA).
- **QR backlash** — 88% US diners prefer paper (Technomic). Static PDF QR = "tacky."

---

## 4. Contradictions: NONE

Zero factual contradictions across all sources. Unusual convergence = well-documented real problem.

**Blind spots:** Non-restaurant SMBs unvalidated. Onboarding transition unaddressed (MenuList already handles). AI agent data consumption under-explored (MenuList ahead with llms.txt).

---

## 5. Four Root Structural Failures

All surface symptoms collapse into four failures:

| # | Failure | Description |
|---|---------|-------------|
| I | **No canonical source** | Every surface = own copy. No upstream authority. |
| II | **No real-time state layer** | Menu treated as document, not live system. |
| III | **Platform control asymmetry** | Google/aggregators override, scrape, delay. Restaurants powerless. |
| IV | **Manual middleware** | Owner = sync engine. Multi-logins, PDFs, verbal corrections. |
