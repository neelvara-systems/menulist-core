## Article Summary

A scenario analysis (written Feb 2026, framed as June 2028 retrospective) modeling what happens if AI progress destabilizes the economy rather than boosting it. Core concept: "Ghost GDP" — output grows but doesn't circulate through human spending because machines produce but don't consume.

Key mechanisms modeled:
1. **SaaS pricing collapse** — Agentic coding makes in-house builds viable, negotiation leverage shifts
2. **Friction-based moat destruction** — Agents remove habitual loyalty, comparison cost → zero, intermediary rent collapses
3. **Intelligence Displacement Spiral** — AI improves → companies replace labor → wages fall → demand falls → more AI → repeat
4. **Financial contagion** — SaaS defaults → private credit → insurance balance sheets → mortgage market
5. **Intelligence Premium Unwind** — Human intelligence loses scarcity premium, institutions built on that assumption reprice
