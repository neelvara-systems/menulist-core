# Global Localization Website Boundary

**Status:** No new public website surface required
**Last updated:** July 17, 2026

This hardening changes shared display correctness; it does not add a marketable feature or new URL.

Public website resource localization remains governed by `__docs__/main-website/main-website_resources-localization-plan.md`. Only reviewed resource packs receive locale-prefixed URLs, sitemap entries, `hreflang`, and discovery exposure.

The owner-app locale registry must not be presented as evidence that all website resources or all owner UI copy are fully reviewed in those languages.
