# Global Localization Marketing Boundary

**Status:** Internal capability note; no standalone campaign
**Last updated:** July 17, 2026

Approved factual statement:

> Owners can choose the dashboard language, timezone, and date/time format. Supported right-to-left languages render in the correct direction.

The checked-in owner UI key tree is populated and semantic-evidence gated in all registered locale packs. Do not claim that every value was written or certified by a native speaker; the expanded coverage is model-assisted, protected, and source-gated.

Do not merge this capability with menu-content translation. Owner UI language and customer-visible menu languages are separate controls.
