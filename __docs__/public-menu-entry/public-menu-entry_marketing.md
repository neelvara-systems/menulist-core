## Approved position

Start with one menu photo, a PDF of up to 15 pages, or a public menu link you have permission to use. Review the prepared menu, create the owner-controlled public link, and keep updating the same source.

One approved link the owner can place in QR, WhatsApp, and Google profile surfaces. Customers see the owner-published menu through owner-controlled save and publish paths.

## Allowed claims

- Public entry page; signed-in processing.
- First structured setup preview before plan selection.
- Camera, saved photo, bounded PDF, or supported public link input.
- Owner review before the menu is created.
- Permanent MenuList URL controlled by the owner.
- Existing customers can add a menu to their current account.

## Do not claim

- Anonymous or unlimited extraction.
- Automatic publishing without owner review.
- Guaranteed perfect extraction, provider availability, or fixed processing time.
- Automatic placement on third-party profiles.
- A subscription or payment is started during preview.
- Current production launch until approved app/Functions release, provider/device/browser, Razorpay-when-relevant, and production-host evidence exists.
- That customers receive a raw PDF viewer. PDF is an owner intake format; the published output is the structured MenuList menu.
