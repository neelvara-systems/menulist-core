## §1 — Feature Section (for canonica.app/product or features page)

### Headline
Structured procedures, not paragraphs.

### Subheadline
Canonica answers "how to" questions with numbered, atomic steps — governed, version-tracked, and deterministic.

### Body Copy
Most AI support tools answer procedural questions with generated text. Users ask "how do I invite a teammate?" and receive a wall of prose. They skim, miss steps, get stuck, and open a ticket.

Canonica serves structured procedure answers: numbered steps, each representing one user action. Steps are human-approved, version-bound, and governed by the same drift detection that monitors all canonical knowledge.

When your product UI changes, Canonica flags outdated procedures automatically. No more silently broken documentation.

### Feature Bullets
- **Atomic steps** — One action per step. No compound instructions.
- **Version-tracked** — Procedures are bound to product versions. Drift detected automatically.
- **Warnings built in** — Destructive actions flagged with severity-based warnings before users execute.
- **Prerequisites visible** — Role, plan, and state requirements shown clearly.
- **Same governance** — Mutation pipeline, drift detection, and audit logging apply equally.
- **Zero extra cost** — Procedure data embedded in existing answer documents.
