## §1 — Positioning

### One-Liner

"Your support tickets automatically become knowledge — so the same question never costs you twice."

### Elevator Pitch

Every resolved support ticket contains knowledge that should be in your help center. Canonica's Ticket → Knowledge Loop automatically detects when multiple tickets cluster around the same topic, extracts the resolution pattern, and proposes a ready-to-approve help article. Your knowledge base grows from real support interactions — not manual documentation effort.

### Competitive Positioning

| Competitor | Their Approach | Canonica's Approach |
|------------|---------------|---------------------|
| Intercom Fin Suggestions | Conversations → article suggestions (similar architecture) | Entity-bound accumulation (more precise, less noise) |
| Zendesk Content Cues | Analytics → gap detection (surface-level) | Deep resolution extraction + structured canonical answers |
| Freshdesk | Manual KB gap reports | Fully automated pipeline with governance |
| Generic AI helpdesks | No ticket→knowledge pipeline | Built into the governance infrastructure |

## §3 — Feature Benefits

| Benefit | Description |
|---------|-------------|
| **Zero manual effort** | Knowledge suggestions appear automatically in your review queue |
| **Quality through accumulation** | Only proposes knowledge when 3+ tickets confirm the same issue |
| **One-click publishing** | Review and approve with a single click |
| **Full provenance** | Every article tracks which tickets generated it |
| **Cost-controlled** | Capped AI processing, predictable monthly cost |
| **Privacy-safe** | Strips PII from ticket conversations before knowledge extraction |

---

## §4 — Objection Handling

| Objection | Response |
|-----------|----------|
| "Won't it create garbage articles?" | Accumulation prevents single-ticket noise. 3+ tickets must agree. Founder approval is mandatory. |
| "We don't have enough tickets" | System adapts — even 10 tickets/month can surface patterns over time |
| "How is this different from just reading tickets?" | It cross-verifies resolutions across conversations and structures them into publishable knowledge |
| "What about sensitive ticket content?" | AI is instructed to strip PII. Founder reviews before publishing. |
