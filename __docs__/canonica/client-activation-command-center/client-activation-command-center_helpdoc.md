# Help Doc: Launching Canonica

Open Activation from the Canonica dashboard.

Use the checklist from top to bottom:

1. Confirm your license.
2. Add help content.
3. Map product surfaces.
4. Create or confirm the widget key.
5. Lock allowed origins.
6. Install the widget in your product.
7. Pass page context after route changes.

When all required checks are done, Canonica is ready for customer traffic.
