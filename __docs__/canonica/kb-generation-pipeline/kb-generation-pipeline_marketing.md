> **Version:** 1.0.0
> **Last Updated:** 2026-03-02
> **Audience:** Sales, Marketing (Internal)

---

## 1. Elevator Pitch

**One-liner:** "Upload your docs. AI generates structured help articles. Review and publish."

**30 seconds:** Instead of manually writing help articles one by one, upload your existing documentation — PDFs, documents, videos, website URLs — and the AI generates structured knowledge base articles organized into categories and sections. Review what was generated, resolve any duplicates, and publish. Every article is automatically embedded for semantic search by the AI chatbot.

---

## 2. Key Selling Points

| Point | Evidence |
|-------|---------|
| **Multi-format input** | PDF, Image, Video, Audio, Document, Website, YouTube, Google Drive, Copied Text |
| **AI-structured output** | Categories → Sections → Articles with rich TipTap content |
| **Human-in-the-loop** | AI generates, humans review — no auto-publish |
| **Duplicate detection** | Reconciliation for articles similar to existing KB content |
| **Auto-embedding** | Every published article gets 768-dim vector for RAG search |
| **Source provenance** | Each article tracks which file and page generated it |
| **Real-time progress** | Live status updates during processing and publishing |
| **Cost:** | ~$0.02/month for typical usage |
