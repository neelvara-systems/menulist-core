# Canonica Scheduler Architecture Helpdoc

## What It Does

Canonica checks your product knowledge automatically after your workspace day ends.

You can set:

- Workspace timezone
- Support day end time

These settings decide when daily governance work runs for your workspace.

## Owner Action

No action is normally needed. Set the timezone once in Settings and leave the rest automatic.

The Activation screen shows Daily Governance status, the support-day end time, the next daily check window, and the last completed workspace run. Use Settings if the timezone or support-day close time is wrong.
