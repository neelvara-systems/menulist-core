# Support Board Website Guidance

Support Board can be mentioned on the Canonica public website only as an internal owner workflow.

Safe claim:

> Canonica gives owners a Support Board where tickets, missed questions, and support gaps can become reviewable knowledge work.

Do not claim:

- full project management
- full helpdesk replacement
- public roadmap
- SLA automation
- automatic answer publishing
- automatic card creation from every runtime event

Best placement:

- Product page, under Support Control
- Homepage, in the closed-loop section
- FAQ, as an answer to "What happens when Canonica misses an answer?"

Feature wording:

- "Support Board"
- "Needs Answer queue"
- "Internal owner notes"
- "Create an answer proposal"

Avoid "Owner Notes" as the main feature name because it sounds generic and undersells the support-loop value.
