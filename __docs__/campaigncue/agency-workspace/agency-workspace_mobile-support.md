# Agency Workspace - Mobile Support

## Mobile Admission

Agency Workspace is mobile-relevant for approval checks, quick comments, and client switching, but deep setup should remain desktop-first.

## Mobile Requirements

- Show assigned clients in a compact switcher.
- Surface pending approvals and due tasks first.
- Allow comments, approve/reject, and report sharing from phone.
- Keep client name/location visible to avoid wrong-client action.
- Avoid dense multi-client tables as the primary phone view.

## Mobile Non-Goals

- Bulk client onboarding.
- Full template builder.
- Role administration.

## Acceptance

- Agency user can approve/check a client campaign from mobile without losing client context.
- Client owner can approve or comment from mobile.
