# Agency Workspace - Help Doc

## What This Does

Agency Workspace helps an agency manage campaign work for multiple local-business clients.

## Main Actions

- Switch between assigned clients.
- Create campaign packs.
- Send approval requests.
- Reuse templates.
- Export or publish approved work.
- Share result reports.

## Approval Rules

Approvals apply to the exact campaign output version sent to the client. If the agency edits the output after approval, a new approval may be required.

## Client Separation

Client data stays inside the assigned client workspace. Templates can be reused, but client facts should not be copied into another client's campaign.
