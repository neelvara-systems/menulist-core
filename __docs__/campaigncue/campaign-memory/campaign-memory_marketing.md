# Campaign Memory 2.0 - Marketing Boundary

## Approved Description

Campaign Memory keeps a compact record of owner-reported outcomes and uses that evidence to suggest what to repeat, review, or test next.

## Approved Claims

- Remember which campaign recipes owners reported as useful.
- Keep result confidence visible.
- Use manual results without connecting social accounts.
- Turn repeated evidence into one practical next step.
- Recheck current facts before reusing a pack.

## Rejected Claims

- `CampaignCue proves which campaign caused revenue.`
- `CampaignCue predicts your next winning campaign.`
- `Automatic ROI attribution.`
- `Guaranteed growth from past results.`
- `AI learns every customer.`

## Positioning

The value is disciplined memory for a busy owner, not an analytics theater layer. CampaignCue can say what evidence it has, how limited that evidence is, and what small next action is reasonable.
