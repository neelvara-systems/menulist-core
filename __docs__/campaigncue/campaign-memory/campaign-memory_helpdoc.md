# Campaign Memory 2.0 - Owner Help

## What Campaign Memory Means

Campaign Memory uses the results you record after a campaign. It can help you notice a useful recipe or channel, but it does not prove that one post caused every reply, booking, order, or walk-in.

## Record A Result

1. Open **Results**.
2. Choose the campaign you used.
3. Choose what happened.
4. Add any counts you know.
5. Save the result.

Use `Not used yet` when the pack was prepared but not shared. Use `Not useful` when it did not fit the business moment.

## Read The Memory

- `Not enough results`: record another real outcome before changing strategy.
- `Early signal`: the pattern may be useful, but keep the next test small.
- `Repeated signal`: several owner-reported results point in the same direction. Recheck current facts before repeating the pack.

CampaignCue always rebuilds reusable packs from current business facts. It does not copy an old price, date, phone number, or offer without rechecking it.
