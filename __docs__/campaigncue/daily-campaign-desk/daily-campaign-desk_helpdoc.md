# Daily Campaign Desk — Help

## What Is Daily Campaign Desk?

Daily Campaign Desk shows the next campaign action for the business.

It may ask for a missing detail, show a ready campaign pack, list manual use steps, suggest a photo task, show image-reuse options, request approval, show a due reminder, ask for a result, or offer to safely rebuild a campaign recipe that helped before.

## How To Use It

1. Open CampaignCue.
2. Start with the first action on Daily desk.
3. If a detail is missing, open the linked section and save it.
4. Create or open the campaign pack.
5. Download the pack or a single output.
6. If useful, choose a local date/time for a manual reminder. CampaignCue does not post automatically.
7. Use the manual steps for WhatsApp, Google, social, print, or the store.
8. Mark the pack used.
9. Add a short result note or choose a quick result option when something happens.

**Pack readiness** checks facts, trust, freshness, approval, and manual handoff. It does not predict engagement or sales.

**Reuse safely** creates a new campaign from current checked facts. It does not copy the old campaign's files, approval, or trust state.

## What It Does Not Do

CampaignCue does not post directly to social accounts from Daily desk. It prepares the pack for download and manual use.

## When To Open The Editor

Open the editor only for last-mile changes. Use Design Cue for simple text or layout requests. Use CueLayers when an existing flat image needs safe reusable layers.
