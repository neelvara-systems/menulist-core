# Opportunity Engine — Documentation

Opportunity Engine currently creates deterministic campaign cues from Business Brain, source snapshot, and readiness state. Source changes, missing assets, calendar events, MenuList signals, salon slots, and prior campaign usage remain architecture inputs that must stay bounded before they are activated.
