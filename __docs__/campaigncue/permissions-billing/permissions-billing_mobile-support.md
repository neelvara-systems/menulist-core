# Permissions Billing - Mobile Support

## Mobile Admission

Permissions Billing is mobile-relevant for credit confirmation, approvals, and role-safe actions. Deep billing setup remains desktop-first.

## Mobile Requirements

- Show credit estimate before generation or render.
- Keep approve, confirm, and cancel actions clearly separated.
- Show when the user lacks permission.
- Show monthly usage summary to owners and billing admins.
- Block spend-changing actions without explicit confirmation.

## Mobile Non-Goals

- Full invoice management.
- Complex role matrix editing.
- Payment method setup as the primary phone flow.

## Acceptance

- Owner can understand credit impact before creating a campaign asset on mobile.
- User without permission sees a clear blocked state, not a hidden failure.
