# Calendar Scheduler - Documentation

Calendar Scheduler is the lightweight manual-task calendar for CampaignCue. It stores an owner-selected local date/time, channel, optional assignee label, and task type for a campaign pack. It does not publish, send, poll providers, or run a background due-job worker.
