# Calendar Scheduler - Help Doc

## What This Does

Calendar Scheduler helps plan when campaign outputs should be posted, exported, or reviewed.

## How To Use It

1. Open an approved campaign pack.
2. Choose the channels to schedule.
3. Pick date and time.
4. Confirm whether each channel is automatic or manual.
5. Save the schedule.
6. Watch the calendar for due, published, failed, or manual-task status.

## Status Meanings

- `Draft`: not ready to schedule.
- `Needs approval`: owner approval is still required.
- `Scheduled`: ready for the planned time.
- `Manual task`: owner or agency must complete outside CampaignCue.
- `Published`: connected channel reported success.
- `Failed`: connected channel could not complete the action.
