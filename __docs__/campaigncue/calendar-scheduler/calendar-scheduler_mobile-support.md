# Calendar Scheduler - Mobile Support

## Mobile Admission

Calendar Scheduler is mobile-relevant for owner approval, reminders, and status checks.

## Mobile Requirements

- Provide agenda-first mobile view.
- Show channel, time, approval, and manual/automatic status.
- Keep approve, reschedule, mark done, and view campaign actions large.
- Avoid month-grid density as the primary phone experience.
- Make timezone and manual task status clear.

## Mobile Non-Goals

- Bulk schedule editing.
- Drag-and-drop calendar management.
- Complex recurring campaign rules.

## Acceptance

- Owner can see today/upcoming campaign tasks from mobile.
- Owner can approve, reschedule, or mark manual task done from mobile.
