# Calendar Scheduler - Mobile Support

## Mobile Admission

Calendar Scheduler is mobile-relevant for reviewing manual reminders and choosing a local task time. Full calendar management is not part of the current mobile scope.

## Mobile Requirements

- Provide agenda-first mobile view.
- Show channel, local time, task type, assignee, and manual-only status.
- Keep create-reminder and open-campaign actions at least 44px high.
- Avoid month-grid density as the primary phone experience.
- Make timezone and manual task status clear.

## Mobile Non-Goals

- Bulk schedule editing.
- Drag-and-drop calendar management.
- Complex recurring campaign rules.
- Reschedule, completion, retry, and cancellation controls until their server contracts exist.

## Acceptance

- Owner can see today/upcoming campaign tasks from mobile.
- Owner can choose an explicit local time and create a manual reminder.
- Mobile copy never implies automatic posting or sending.
