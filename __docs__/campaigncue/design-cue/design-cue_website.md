# Design Cue - Website Content

## Public Copy Boundary

Design Cue may be described publicly only when the implementation exists behind the CampaignCue editor.

Allowed copy:

> Ask for simple design changes in plain language, review the suggested edit, and export when ready.

Supporting copy:

- Add local details without hunting through design controls.
- Check business facts before using an asset.
- Keep edits manual and reviewable.
- Download/export remains the active delivery path.

Do not claim:

- direct social posting
- automatic ad creation
- hands-free publishing
- perfect design generation
- replacement for a professional designer
