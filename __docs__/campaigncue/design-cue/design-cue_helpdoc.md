# Design Cue - Help Doc

## What This Does

Design Cue helps you ask for simple design changes in normal words.

Examples:

- Make the offer clearer.
- Add my contact line.
- Make this fit a story.
- Check if facts look right.
- Make this text shorter.

## How It Works

1. Open a design in Creative Studio.
2. Open Design Cue.
3. Choose a suggested action or type what you want changed.
4. Review the proposed change.
5. Apply it only if it looks right.
6. Download/export the final asset.

## What To Review

Before using the asset, check:

- business name
- phone/WhatsApp/booking link
- prices
- dates
- location
- image rights
- spelling

## What It Does Not Do

Design Cue does not post, send, connect accounts, or spend ad budget. It prepares editable changes and export-ready assets for manual use.
