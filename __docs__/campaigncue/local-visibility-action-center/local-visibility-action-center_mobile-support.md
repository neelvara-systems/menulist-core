# Local Visibility Action Center - Mobile Support

Mobile uses the existing CampaignCue shell and overview payload.

- Show the attention summary before the full list.
- Keep one primary action per card with at least a 44px target.
- Put evidence, steps, and unlocks in a vertical reading order.
- Route to existing shell tabs; do not bypass the mobile shell.
- Allow review, source correction, manual copy/download, and result capture.
- Do not open dense creative editing as the default mobile action.
- Preserve translated shell/navigation behavior; dynamic business truth remains owner-entered content.

No mobile-only Firebase read, listener, or provider call is permitted.
