# Pattern Cue - Spec

## Owner Problem

SMB owners often see a useful reel or post but do not know how to translate its format to their business without copying it, inventing claims, or opening another generic creator tool.

## Product Promise

Submit one public example. CampaignCue extracts the reusable format, creates original business-specific hook options, and carries the format into the next reel or creator brief using checked business facts.

## Inputs

- Short owner label
- Public HTTPS source link
- Platform or automatic host detection
- Approximate duration
- Transcript or owner format notes
- Optional owner takeaway
- Rights posture: format reference only or owner-authorized source

## Outputs

- Hook category
- Format and pacing
- Duration band
- Structural sequence
- Visual beats
- CTA category
- Three original hooks based on Business Brain facts
- Originality, rights, consent, claim, and disclosure guardrails

## Invariants

1. Raw transcript/notes are never persisted.
2. Pattern observations never become Business Brain facts.
3. Pattern input cannot satisfy campaign price, date, availability, offer, location, CTA, or asset-readiness gates.
4. Only the latest owner-approved example is retained.
5. Only video and UGC outputs use Pattern Cue.
6. Campaign packs pin the pattern source ID and hash.
7. Replacing the current example makes only packs that used the old example stale.
8. Manual export and owner approval remain mandatory.

## Non-Goals

- No account spying, follower surveillance, scheduled refresh, scraping, or viral alerts.
- No copied scripts, captions, footage, music, creator identity, or distinctive wording.
- No AI-avatar-first output or fictional customer experience.
- No creator marketplace, CRM, contracts, payments, or guaranteed performance.
- No direct posting.
