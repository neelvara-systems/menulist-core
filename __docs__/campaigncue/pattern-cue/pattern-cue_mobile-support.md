# Pattern Cue - Mobile Support

Pattern Cue is mobile-relevant because owners discover examples and prepare phone-shot reels on mobile.

## Supported

- Open Examples from the shared CampaignCue sidebar/shell.
- Paste a public link and notes.
- Choose rights posture and approximate duration.
- Save the current pattern.
- Review original hooks and open the public example.
- Continue to pack review/download.
- Follow the derived Video Reel Studio phone shot list and open the matching scene.
- Record the owner's outcome for the exact rendered version after manual use.

## UX Requirements

- Inputs use the existing responsive form grid.
- Primary action remains a 44px-friendly CampaignCue button.
- Long source links and hooks wrap without horizontal overflow.
- Pattern Cue does not introduce dense mobile video editing.
- No mobile background monitor, account refresh, creator feed, or additional listener is introduced.
