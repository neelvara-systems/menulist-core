# Analytics Learning - Help Doc

## What This Does

Analytics Learning shows what happened after a campaign and helps decide what to try next.

## Metric Sources

- `Observed`: CampaignCue directly recorded the action.
- `Imported`: a connected platform reported the number.
- `Manual`: a person entered the result.
- `Estimated`: CampaignCue calculated a directional value from available data.

## How To Use It

1. Open a completed campaign.
2. Review channel results.
3. Check metric source labels.
4. Add manual results if needed.
5. Review suggested next cues.
6. Save or share a report if needed.

## Important

Some platforms delay or limit metrics. Treat results as campaign guidance, not a complete accounting system.
