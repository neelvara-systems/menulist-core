# Analytics Learning - Mobile Support

## Mobile Admission

Analytics Learning is mobile-relevant because owners need quick campaign status and result review.

## Mobile Requirements

- Show summary first, then channel detail.
- Keep metric source labels visible.
- Provide simple next-cue actions.
- Allow manual result entry with large inputs.
- Avoid dense charts as the only view.

## Mobile Non-Goals

- Advanced report builder.
- Deep attribution modeling.
- Large data exports.

## Acceptance

- Owner can understand whether a campaign was sent, seen, clicked, replied to, or manually completed from mobile.
- Owner can accept a next cue from the result screen.
