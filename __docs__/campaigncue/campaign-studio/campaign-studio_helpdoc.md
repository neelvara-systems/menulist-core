# Campaign Studio — Help Documentation

## Quick Summary

Campaign Studio creates a campaign pack from a goal, item, service, offer, or campaign cue.

## Create A Campaign

1. Open **Create Campaign**.
2. Choose the goal.
3. Select the item, service, offer, or location.
4. Choose outputs.
5. Review the channels and cost posture.
6. Create the pack.
7. Review the generated pack.

## Duplicate A Campaign

1. Open the old campaign.
2. Click **Duplicate**.
3. Refresh the source when prompted.
4. Review any changed price, service, or location detail.

## Troubleshooting

### Some outputs failed

Use the completed outputs or retry failed ones. Credits for failed outputs should be returned.

In the current runtime, paid generation is disabled and no credits are charged.
