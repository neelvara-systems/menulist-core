# Campaign Pack Output System — Website Copy

## Allowed Public Copy

CampaignCue prepares a complete campaign pack: copy, channel handoff fields, trust checks, reuse notes, and result prompts in one download.

Use when public copy needs to explain export/download:

> Download one campaign pack with the messages, handoff fields, checks, and follow-up prompt ready for manual use.

## Required Boundary Copy

CampaignCue does not directly post, send WhatsApp messages, connect provider accounts, or start ad spend in the current runtime.

## Avoid

- "autopilot marketing"
- "one-click posting"
- "AI knows what to promote"
- "instant social publishing"
