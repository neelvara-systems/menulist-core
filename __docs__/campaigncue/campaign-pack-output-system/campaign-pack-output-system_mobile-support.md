# Campaign Pack Output System — Mobile Support

## Admission Test

| Gate | Result | Reason |
| --- | --- | --- |
| Frequency | Pass | Owners may download/copy packs on the same day they use them. |
| Speed | Pass | Summary and ZIP generation use already-loaded data and one tap. |
| Touch | Pass | Existing CampaignCue buttons use 44px minimum targets. |
| Owner value | Pass | Owners often need WhatsApp/staff/copy handoff from a phone. |

## Mobile Behavior

- Output pack summary uses existing responsive CampaignCue cards.
- The ZIP button remains a single clear action.
- Channel fields remain copyable through existing manual delivery cards.
- No mobile-only data path is added.
- No direct social app posting is triggered from the browser.

## Constraints

Some mobile browsers handle ZIP downloads differently. Owner help copy should tell owners that the downloaded ZIP is a package of text/brief files and that channel posting remains manual.
