# Vertical Campaign Playbooks - Website Boundary

The website may explain that CampaignCue uses curated local-business action playbooks to recommend source-backed campaign packs. Examples may include lunch, appointment availability, product stock, service maintenance, class trials, and careful clinic notices.

Public copy must not describe the registry as autonomous strategy, guaranteed growth, a template marketplace, or direct publishing. It should state that recommendations depend on owner-confirmed facts and manual use.
