# How Vertical Campaign Playbooks Help

CampaignCue uses a small set of business-action playbooks rather than asking you to browse generic templates.

For example, it may help a restaurant prepare a catering inquiry pack, a salon remind existing members, a shop announce an item that is back in stock, or a local service prepare a seasonal-maintenance reminder.

CampaignCue still asks for missing facts before creating the final pack. It does not invent prices, stock, dates, availability, contact details, claims, or photo permission.
