# Publish A Campaign Page And QR

1. Open a ready Campaign Pack.
2. Review the facts, destination, terms, and expiry.
3. Select **Publish page**.
4. Open or copy the page link.
5. Download the QR if you need it on a counter card, flyer, or staff handoff.
6. Unpublish the page when the offer or campaign should no longer be available.

CampaignCue blocks publishing when the pack is stale, expired, incomplete, or unsafe. The page does not post anywhere automatically and it does not track visitors.
