# Campaign Inbox - Owner Help

## Tell CampaignCue What Changed

Open **Offers, events, and notes** and use **Tell CampaignCue what changed**.

Add one detail per line when possible:

```text
Offer: Weekend haircut package
Price: INR 799
Availability: Four Saturday slots
Ends: Sunday at 6 PM
```

Select **Review update**. CampaignCue will show each detail before anything is saved.

## Review The Details

- Keep selected only the details you want CampaignCue to use.
- `Ready to use` means the detail can be considered by campaign recommendations.
- `Needs review` means it stays visible but is not used as ready truth.
- Phone, WhatsApp, location, website, menu link, and booking link go to **Business Details** because those details are reused across campaigns.

Select **Save selected details** after checking the list.

## What CampaignCue Does Not Do

- It does not post or send anything.
- It does not change business details without your review.
- It does not invent missing prices, dates, discounts, or availability.
- It does not save the draft before you confirm it.

For a complex entry, use the detailed source form below the Inbox.
