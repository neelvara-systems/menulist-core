# API Boundaries - Marketing Notes

## Positioning

CampaignCue integrates with campaign channels and providers through controlled connections and export workflows.

## Buyer Promise

- Connected workflows where the provider and workspace are configured.
- Manual export when direct API action is unavailable.
- Clear status when a provider action fails or is unsupported.
- Agency and client integration posture without data blending.

## Proof Points

- Provider adapters.
- Webhook status capture.
- Manual fallback.
- Versioned integration contracts.

## Avoid

- Do not claim open API availability before it is enabled.
- Do not promise every platform can be published to directly.
- Do not imply CampaignCue owns provider approval, quotas, or policy decisions.
