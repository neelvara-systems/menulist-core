# Video Reel Studio - Help Doc

## What This Does

Video Reel Studio turns a checked CampaignCue reel plan into an editable, downloadable short video. CampaignCue creates the motion locally in your browser; it does not send the project to Topview or another video-render service.

## What You Get

- Three bounded hook/caption directions.
- An editable scene list with timing, overlays, CTA, motion, and transitions.
- Text-only motion or motion using a private image or video clip you control.
- Optional burned-in captions, separate narration and background music, local narration recording, volume control, and background ducking.
- Portrait, square, or landscape output.
- A six-part content check for opening, owner-controlled proof, pacing, readable text, final action, and facts/rights. Generated visuals can support the design, but they are not labeled as real business proof.
- A phone shot list that opens the matching scene and shows which shots still need media.
- Version history, optional human review notes, owner approval, cancellable render jobs, version-bound result memory, and reusable layouts.

## How To Use It

1. Open **Reels** and choose a checked video output.
2. Select **Create video project**.
3. Pick a hook direction and format.
4. Review the **Video content coach** and **Phone shot list**. Open a highlighted scene and edit only wording that remains true for the business.
5. Optionally upload owned media to the private Asset Library or select a session-only image/video. Add narration and background music separately, then confirm rights for session media.
6. Save. CampaignCue reruns its trust checks. The content coach is guidance and never changes the project by itself.
7. Optionally ask a staff member, adviser, agency, or client to review the opening, proof, or final action. Resolve any note before approval.
8. Approve the current version.
9. Select **Render and download**. Keep the tab open until the download starts.
10. Post the downloaded file manually in the channel you choose.
11. Record whether that rendered version was useful. CampaignCue remembers only the compact format outcome. Useful videos expose a structural layout from the version that produced the file, without copying old campaign facts or media.

You can select **Download storyboard** at any time. It creates a plain-text scene plan for a staff shoot or for browsers that cannot record the final video.

## Important Boundaries

- Session-only image/video/audio is not automatically saved. Explicit Asset Library upload is private and reusable.
- MP4 appears only when the browser supports native MP4 recording; otherwise CampaignCue downloads WebM.
- Use only footage, images, voices, people, logos, and music you have permission to use.
- Do not present fictional or synthetic people as customers or staff.
- CampaignCue does not publish, boost, buy ads, or guarantee results.
- Older render receipts that predate exact version binding remain visible, but you must render again before using them for format learning.

## If Rendering Fails

Your project is still saved. Cancel if needed, close an interrupted attempt, remove an unsupported media file, keep the tab active, or try a current Chromium/Safari browser. Select **Download storyboard** to keep using the checked scene plan manually.
