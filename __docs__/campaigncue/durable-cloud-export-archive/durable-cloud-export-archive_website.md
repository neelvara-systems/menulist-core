# Durable Cloud Export Archive Website Boundary

## Current Website Decision

Do not add a homepage section, feature page, comparison claim, or pricing entitlement for cloud archives yet. The code is locally implemented, but Firebase project deployment, bucket CORS, signing permissions, and authenticated QA evidence are not confirmed in this repository session.

## After Activation Evidence

The capability may appear as a supporting Campaign Pack detail:

> Keep the current Campaign Pack in your workspace and download it again later.

It must remain subordinate to CampaignCue's primary promise: decide, prepare, verify, use manually, and learn.

## Copy Guardrails

- Say `current cloud copy`, not `backup vault`.
- Say `download again`, not `share publicly`.
- Do not mention two-slot storage internals.
- Do not imply direct posting or provider connection.
- Do not advertise unlimited history or storage.

Public copy should be enabled only after the validation document records authenticated QA and production evidence.
