# Durable Cloud Export Archive Marketing Boundary

## Allowed Description

CampaignCue can keep the current Campaign Pack ZIP in the owner's workspace for later download.

## Allowed Benefits

- Return to the current reviewed pack later.
- Keep campaign files and instructions together.
- Replace the current copy without creating an unlimited history.
- Download through short-lived private access.

## Prohibited Claims

Do not claim:

- unlimited cloud storage;
- permanent backup or disaster recovery;
- version history or rollback;
- public share links;
- automatic social delivery;
- provider account integration;
- guaranteed retention;
- legal/compliance record storage.

Until QA and production Storage rules, CORS, IAM signing, and authenticated browser evidence pass, this feature must not be marketed as live.
