# Refresh A Campaign That Helped Before

When CampaignCue has a useful owner-reported result, it may show **Refresh safely**.

1. Review why the earlier pack was nominated.
2. Check whether it is recommended now or needs review.
3. Confirm any missing current price, date, availability, photo permission, or destination.
4. Create the refreshed pack.
5. Review Trust Center and approval again.
6. Download or copy the manual handoff files.
7. Record the new result separately.

CampaignCue does not copy old facts or assume the same result will happen again.
