# Winning Pack Refresh - Mobile Support

- The Daily Desk shows one bounded refresh candidate, not a history browser.
- The primary action uses the existing 44px-safe CampaignCue button treatment.
- Evidence, current-fit state, and seasonal context wrap without horizontal scrolling.
- Mobile can create, review, download, and record the result of a refreshed pack.
- Dense visual editing remains a desktop workflow; mobile review does not open a second editor runtime.
