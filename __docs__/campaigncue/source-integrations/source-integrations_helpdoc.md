# Source Integrations — Help Documentation

## Quick Summary

Sources bring business details into CampaignCue. You can connect a source, upload a file, add details manually, or use manual mode when a connection is unavailable.

## Connect MenuList

1. Choose **Restaurant** during setup.
2. Click **Connect MenuList**.
3. Review requested read-only access.
4. Select the store or outlet.
5. Wait for sync to finish.
6. Review the first campaign cues.

## Upload A Menu Or Service List

1. Open **Sources**.
2. Click **Upload file**.
3. Choose PDF, image, CSV, or supported document.
4. Review detected items or services.
5. Confirm or edit unclear fields.

## Troubleshooting

### Source sync failed

Use last synced data or retry. If it keeps failing, continue in manual mode.

### Detected prices look wrong

Review the extraction screen and mark the correct price before using it in a campaign.
