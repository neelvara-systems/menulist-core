# Source Integrations — Marketing

## Pitch

CampaignCue can start from the data a business already has.

## Talking Points

| Source | Message |
| --- | --- |
| MenuList | Use official menu facts in campaigns without changing the menu. |
| Upload | Turn existing menu or service files into campaign context. |
| Website | Pull public details into a review screen before use. |
| Google/WhatsApp/Meta | Request setup only when direct publish or channel data is useful; manual mode remains the default. |

## Avoid

- "We scrape everything"
- "CampaignCue owns your menu"
- "Connect every app before value"
- "Automatic public profile changes"
