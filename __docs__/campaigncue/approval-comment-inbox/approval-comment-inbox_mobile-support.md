# Approval and Comment Inbox - Mobile Support

- Keep review cards inside the CampaignCue mobile shell.
- Show state, open-count, comment text, and one resolve action in a vertical layout.
- Use at least 44px touch targets for comment, resolve, approve, and reject.
- Disable approve visibly while open comments remain.
- Keep rejection note and comment entry separate so the owner understands the outcome.
- Mobile is suitable for review, comments, approval, rejection, download, and result capture; dense creative editing remains desktop-first.
- No mobile-only listener, query, or route is added.
