# Approval and Comment Inbox - Owner Guide

1. Open **Agency Workspace**.
2. Request approval for the Campaign Pack.
3. Add a short, specific review comment when something needs clarification or change.
4. Resolve each comment after the change has been checked.
5. Approve only when no comment remains open, or reject with a short decision note when the pack must return for changes.

Approval confirms that a person reviewed the pack. It does not replace fact, rights, freshness, or Trust Center checks.
