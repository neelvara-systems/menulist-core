# Read-Only Result Evidence Website Contract

This feature is supporting product depth, not a homepage headline.

## Where it belongs

- Results or Campaign Memory feature detail;
- trust and evidence explanation;
- product FAQ about integrations and attribution;
- campaign pack walkthrough after manual use.

## Public copy

Use:

> Add selected totals from a report you already use and keep the source and date window beside the campaign.

Always pair it with:

> Directional evidence only. CampaignCue does not claim the campaign caused those totals.

## Public exclusions

Do not show connected-account states, automatic sync, live dashboards, provider logos implying partnership, or performance attribution until a verified provider connector is actually active.
