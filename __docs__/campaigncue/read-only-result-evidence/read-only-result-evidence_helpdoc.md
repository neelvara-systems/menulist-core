# Add Numbers From A Provider Report

Use this when you can see useful totals in a provider report and want to keep a small reference beside a CampaignCue pack.

1. Open **Results**.
2. Choose the campaign.
3. Under **Numbers from a provider report**, choose the report source.
4. Choose whether the report covers this campaign, a location window, or the whole account.
5. Add the report start and end dates.
6. Copy one or more totals from the report.
7. Optionally add a short note describing where you copied the numbers from.
8. Select **Save report snapshot**.

CampaignCue keeps only the latest compact snapshot. These numbers are a reference, not proof that the campaign caused the result. They do not change Campaign Memory recommendations.

For campaign learning, still record what actually happened using the owner result options such as replies, bookings, orders, walk-ins, not used, or not useful.

CampaignCue does not connect to, post to, or change anything in the provider account through this form.
