# Use A One-Change Test

CampaignCue may suggest one small change for a Campaign Pack, such as trying a different time or using one approved real photo.

1. Review the reason and the details CampaignCue says to keep unchanged.
2. Select **Use this test** only when you intend to make that one change.
3. Use the campaign through your normal manual workflow.
4. When recording the result, choose the tested variable only if it was the one thing you actually changed.

`Guidance only` means CampaignCue does not yet have a comparable owner-reported result. `Based on owner-reported history` means the suggestion uses your bounded CampaignCue result memory. Neither status predicts performance.
