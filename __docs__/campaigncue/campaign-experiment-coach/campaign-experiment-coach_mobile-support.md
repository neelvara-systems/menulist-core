# Campaign Experiment Coach - Mobile Support

Mobile owners use the existing CampaignCue shell and Campaign Pack cards. The surface shows:

- the one proposed change;
- a short reason and up to two evidence points;
- what should stay unchanged;
- guidance-only or owner-history evidence;
- one `Use this test` action; and
- the current suggested, in-use, or result-recorded state.

Result Memory keeps the tested-variable selector explicit. CampaignCue does not auto-select the suggested variable. Touch actions use the existing mobile-safe CampaignCue controls and no dense chart, split-test builder, or full analytics editor is added.
