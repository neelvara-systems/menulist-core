# Photo And Clip Missions - Marketing Boundary

## Approved Message

CampaignCue can ask for one useful real-business photo or clip, store it privately, and use its verified Asset Library record when checking campaign readiness.

## Approved Claims

- Guided real-photo tasks for campaign preparation.
- Private, reusable CampaignCue media storage.
- Explicit rights and consent review.
- Existing campaign readiness updates after verified upload.

## Prohibited Claims

- CampaignCue proves ownership or consent automatically.
- CampaignCue recognizes or verifies people in a photo.
- A real photo guarantees better performance.
- CampaignCue posts the media automatically.
- CampaignCue enhances every file with AI.
