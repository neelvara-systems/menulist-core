# Add A Photo Or Clip For A Campaign

When CampaignCue needs a real visual, the Daily Desk shows one short task such as `Take one clear photo of today's special`.

1. Open the task and choose `Take photo` or `Choose photo or clip`.
2. Confirm whether people are shown and whether you have permission to use the media.
3. Select the file and wait for the private upload to finish.
4. Review the updated campaign readiness.

`Permission still needs review` keeps the file private and marks it for review. It does not silently make the campaign ready.

CampaignCue preserves the uploaded source in the private Asset Library. It does not post or send the file.

If you only want to record where a file exists, use `Add a file note without upload`. A file note is useful for organization but does not count as a campaign photo.
