# CueLayers - Website Content

## Public Claim Boundary

CueLayers must not claim to recover original Canva, PSD, Photoshop, Figma, or design-tool source files. The public wording must stay honest:

```text
Turn a flat image into editable CampaignCue layers where it is safe, with the original kept as fallback.
```

That sentence describes the long-term gated decomposition contract. The active public page must use the narrower runtime truth: CampaignCue preserves an uploaded flat image as one locked source layer, opens it in the shared editor, and lets the owner add separate editable elements. It must not imply that OCR, segmentation, generated-source intake, or automatic source-layer candidates are active.

## Problem Statement

Small businesses already have useful campaign images, but changing one date, offer, phone number, or branch name often means rebuilding the whole design. That slows down daily marketing and makes old assets hard to reuse.

## Solution Statement

CueLayers preserves an uploaded flat image as a locked source inside CampaignCue. The owner can add verified text, shapes, QR details, or drawing layers in the shared editor, save the revision, and download the result for manual use.

## FAQ

### Does CueLayers recover my original design file?

No. A flat image does not contain guaranteed original design layers. CueLayers creates a safe editable version where possible and keeps the original as fallback.

### Can I upload images from my phone?

Yes, supported image uploads should work from mobile. Full layer editing is easier on desktop.

### Will CampaignCue post the image for me?

No. CampaignCue's active flow is export and download. You decide where to post the final asset.

### What happens if the image cannot be safely separated?

CampaignCue keeps it as a flat image and may add safe editable overlays. It will not pretend that broken layers are ready.

### Can important text change by mistake?

The active flow leaves source text inside the locked image. New editable business text is added separately from confirmed CampaignCue facts instead of silently rewriting the image.
