# CueLayers - Help Documentation

## Quick Summary

CueLayers helps you reuse an existing image. Upload a poster or choose a CampaignCue visual, review the prepared layers, make safe edits, and download the final image.

## What CueLayers Can Do

- Open a flat image inside CampaignCue.
- Keep the original image as a safe fallback.
- Make text or objects editable when it is safe.
- Keep uncertain parts as image layers.
- Let you download the final image for manual posting.

## What CueLayers Cannot Promise

- It cannot recover the original Canva, Photoshop, Figma, or PSD file.
- It cannot make every part editable.
- It does not post directly to WhatsApp, Google, Instagram, Facebook, or ads.
- It should not change important words without review.

## Getting Started

### Prerequisites

- You are signed in to CampaignCue.
- Your image is PNG, JPEG, or WebP.
- You have permission to use the image.
- For best results, use a clear image with readable text.

### Start From An Uploaded Image

1. Open CampaignCue.
2. Go to **Assets** or **Creative**.
3. Click **Turn image into layers**.
4. Choose an image from your device.
5. Wait while CampaignCue prepares the editable version.
6. Open the result when it is ready.

Screenshot slot: Upload panel with file picker and expected time message.

### Start From A CampaignCue Visual

1. Open the campaign or asset you want to reuse.
2. Choose **Turn into layers**.
3. Review the prepared result.
4. Edit safe layers in the editor.
5. Download the final image.

Screenshot slot: Campaign output card with CueLayers action.

## Reviewing The Result

When the editor opens, you may see:

| Label | Meaning |
| --- | --- |
| Editable | This part can be changed safely. |
| Kept as image | CampaignCue kept this part as original pixels for safety. |
| Needs review | This part may be usable, but check it before export. |
| Original fallback | You can restore the original image part if needed. |

## How To Edit

### Change Editable Text

1. Select the text layer.
2. Check that the words are correct.
3. Edit the text.
4. Preview the result.
5. Download the image.

Screenshot slot: Text layer selected with safety label.

### Keep Text As Image

Use this when the words are small, unclear, or important.

1. Select the text layer.
2. Click **Keep as image** or **Restore original**.
3. Preview the result.
4. Download the final image.

### Restore A Layer

1. Select the layer that looks wrong.
2. Click **Restore original**.
3. Check the preview.
4. Save or download again.

### Export The Final Image

1. Click **Save PNG** or **Download**.
2. Save the file.
3. Post it manually wherever you normally work.

CampaignCue does not post it for you.

## Troubleshooting

### My image could not be separated

This can happen when the image has tiny text, heavy compression, watermarks, complex collage, or very low resolution.

What to do:

1. Use the flat image result if it is enough.
2. Upload a clearer image.
3. Add new text in the editor manually.

### The text is not editable

CampaignCue keeps text as image when it is not safe to edit.

What to do:

1. Check if the text is small or unclear.
2. Add a new text layer manually if needed.
3. Keep the original text as image when exact words matter.

### A layer looks wrong

What to do:

1. Select the layer.
2. Use **Restore original**.
3. Replace the image layer if you have a better copy.
4. Export again.

### Export is blocked

This can happen if the design uses an unsupported image, a very large canvas, or unsafe content.

What to do:

1. Remove unsupported images.
2. Use a smaller canvas.
3. Try PNG export again.

## Best Practices

- Use high-quality images.
- Avoid screenshots with very small text.
- Review prices, dates, phone numbers, addresses, and offer terms before export.
- Keep uncertain text as image.
- Use desktop for detailed layer editing.
- Use mobile for upload, preview, and download.
