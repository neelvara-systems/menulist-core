# CueLayers - Marketing And Sales Notes

## Elevator Pitch

CueLayers helps local businesses reuse finished images by turning safe parts of a flat poster or generated visual into editable CampaignCue layers, with the original kept as fallback.

## Feature Narrative

Small business owners already have useful images on their phones: old festival posters, offer creatives, service graphics, food photos, event banners, and agency-delivered visuals. The problem is that changing a date, price, branch name, CTA, or phone number often means rebuilding the entire asset.

CueLayers gives them a practical reuse path. It opens the flat image in CampaignCue, separates editable parts where confidence is high, keeps uncertain parts as image fallback, and exports the final asset for manual posting.

The strongest product story is not "perfect design-file recovery." It is:

```text
Use what you already have. Edit what is safe. Keep the original when it is not.
```

## Positioning

| Alternative | Customer perception | CueLayers position |
| --- | --- | --- |
| Manual design rebuild | Slow and frustrating for small edits. | Reuse the existing image and change safe parts. |
| Generic design tool | Flexible but starts from blank or requires design skill. | Starts from the business owner's actual image and CampaignCue context. |
| Canva Magic Layers | Strong reference point, but broad consumer/design-market positioning. | CampaignCue ties the output to business facts, campaign packs, trust, and export handoff. |
| Codia-style design interpretation | Useful for structured design extraction. | CueLayers should learn from structure/hierarchy extraction while staying CampaignCue/editor-specific. |
| ImageToLayers / RunDiffusion | Practical raster-first layer extraction and designer handoff. | CueLayers adopts raster-first fallback but avoids forcing SMB owners to tune ML thresholds. |
| Adobe Generative Fill layers | Strong non-destructive editing reference. | CueLayers is reverse-reconstruction plus safe repair, not generic image manipulation. |
| Qwen / OmniPSD / Canva MRT research | Shows native layered model direction. | CueLayers keeps schema and correction data ready without depending on frontier model scale. |
| Background remover | Only isolates foreground. | CueLayers aims at editable campaign design objects, text safety, fallback, and export. |
| PSD/image layer tools | Useful for designers, not built for SMB campaign safety. | Owner-safe confidence, warnings, and manual export workflow. |

## Differentiation

- Business facts and brand inputs can become first-class source context.
- Text safety treats prices, dates, address, phone, CTA, and business name as important content.
- The original image is preserved as a locked reference.
- Low-confidence parts stay useful as fallback instead of becoming broken editable objects.
- CueLayers wins on business-safe reuse, not on claiming the highest possible layer count.
- Exports remain manual/download-first, so there is no accidental provider posting or ad spend.
- Correction signals improve reconstruction quality over time.

## Objection Handling

| Objection | Response |
| --- | --- |
| "Is this just a design editor?" | No. The editor already exists. CueLayers is the reuse pipeline that converts existing flat images into safe editable design state. |
| "Will it perfectly recover any Canva/PSD file?" | No. Flattened images do not contain guaranteed original layers. CueLayers creates a safe approximation with fallback. |
| "Can it post directly?" | No. CampaignCue's active delivery model is export/download/manual handoff. |
| "What if text is wrong?" | Text is validated. Unsafe text stays as image or needs review instead of being silently changed. |
| "What if the layers are poor?" | The source image remains available, and the owner can use flat-safe mode or repair targeted parts. |
