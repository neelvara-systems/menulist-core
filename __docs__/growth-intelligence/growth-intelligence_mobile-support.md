# Growth Intelligence Mobile Support

**Status:** Approved  
**Last Updated:** July 10, 2026

Mobile billing must collect the same stable cancellation reason code as desktop before showing the final destructive confirmation. `other` requires bounded detail. The sheet title, prompt, reason labels, validation feedback, and action use the active `Billing` locale. Controls use the existing mobile sheet/list primitives and 44px minimum action targets.

There is no mobile founder-monitor route and no mobile acquisition setup. Public `/create-menu` remains responsive and preserves supported acquisition values through its existing authentication flow.
