# Print Menu Surfaces Marketing

**Status:** Internal
**Last Updated:** June 4, 2026

## One-Liner

Print the menu access points your customers actually see.

## Narrative

Most owners can create a menu link. The hard part is turning that link into clean, visible table and counter objects that customers scan without staff explanation. Print Menu Surfaces gives owners ready-to-print folded table tents, single table/counter cards, and in-store QR assets using their existing MenuList business identity.

## Positioning

| Alternative | MenuList Position |
| --- | --- |
| Plain QR download | MenuList provides the physical card layout, not just the QR. |
| Canva template | No design setup, no export sizing decisions. |
| Printed static menu | MenuList QR always opens the latest live menu. |
| Generic QR stand | Business name, logo, brand color, short link, and attribution policy are applied automatically. |

## Sales Talking Points

- Your table and counter cards are ready before service.
- Customers scan the current menu, not an old PDF.
- The owner does not choose fonts, colors, or layout.
- The same file works from desktop and phone.
- Premium stores can remove visible MenuList attribution.

## Approved Language

- Use: print-ready table card, counter card, table menu QR, live menu, current menu, ready to place.
- Avoid: AI-powered, smart, dynamic, designer, campaign.
