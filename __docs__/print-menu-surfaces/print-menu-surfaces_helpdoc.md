# Print Menu Surfaces Help

**Status:** Help Draft
**Last Updated:** June 4, 2026

## Summary

Print Menu Surfaces gives you table and in-store QR files that customers can scan to open your current menu.

## Download A Table Card

1. Open **Use MenuList** or the **Share** tab.
2. Open the print files section.
3. Download **Table Tent**, **Single Table Card**, or **Complete Menu Kit**.
4. Print the PDF on A5 landscape, 300 GSM matte card.
5. Fold it down the center.
6. Place one card on each table.

## Use A Single Table / Counter Card

1. Open the file `YourName_SingleTableCard_A6.pdf`.
2. Print it on A6 portrait, 300 GSM matte card.
3. Place it in an acrylic holder, counter stand, wall clip, or single-sided table stand.
4. Use this when you do not want a folded table tent.

## Tips

- Use matte paper or matte lamination to reduce glare.
- Test one printed card with a phone before printing many copies.
- Keep the card clean and replace damaged copies.
- Keep one or two paper menus available for customers who ask.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| QR is hard to scan | Print larger, avoid glossy finish, and keep the card upright. |
| Business name is long | MenuList shortens long names automatically on the print file. |
| Menu changed | No reprint is needed if the QR still opens the same live menu. |
