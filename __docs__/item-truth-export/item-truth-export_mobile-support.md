# Item Truth Export Mobile Support

Mobile behavior is inherited from the public menu and PDP modal.

Requirements:
- canonical item links open inside the same PWA/browser route
- no redirect chain
- item is scrolled into view before PDP opens
- highlight is subtle and temporary
- Share, Copy link, and Download use icon buttons with touch-sized targets

Unavailable or deleted items keep the customer on the menu and show `Item not available`.
