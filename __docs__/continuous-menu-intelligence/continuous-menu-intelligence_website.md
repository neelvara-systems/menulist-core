# Continuous Menu Intelligence — Website Boundary

**Last verified:** July 16, 2026
**Decision:** No standalone website page or public capability claim.

CMI is private scheduler-owned infrastructure. The current website must not present it as an owner dashboard, customer feature, automatic optimization system, or public ranking capability.

Website-safe rule:

> Discuss only capabilities that have a current owner or customer surface. Featured Choices has its own page and claim boundary; CMI does not.

Do not use:

- Continuous Menu Intelligence as navigation or a feature heading;
- `AI-powered`, `smart ranking`, machine learning, or neural-network language;
- optimize, promote, demote, hide, reorder, or self-improve claims;
- claims about orders, revenue, conversions, inventory, ratings, or reviews; or
- claims that the menu changes automatically because of CMI.

Historical draft website copy is retained at `_archive/pre-2026-07-16/continuous-menu-intelligence_website.md` and is not current website authority.
