## Language Rules (STRICT)

### USE

- "Observes", "understands", "learns", "notices"
- "Quietly", "silently", "in the background"
- "Customer attention", "browsing behavior", "interaction patterns"

### NEVER USE

- "AI-powered", "Machine learning", "Neural network"
- "Optimizes", "adjusts", "promotes", "demotes", "hides"
- "Automatic menu optimization", "smart ranking"
- "Self-improving menu" (implies active manipulation)

### The Rule

> MenuList **observes** reality. It does not **reinterpret or manipulate** reality.
