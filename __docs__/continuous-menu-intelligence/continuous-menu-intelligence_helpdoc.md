# Continuous Menu Intelligence — Help Documentation

**Last Updated:** March 15, 2026

## Quick Summary

MenuList quietly observes how customers interact with your menu every day. It learns which items attract attention, which ones get overlooked, and how browsing patterns change over time — all in the background, with no action needed from you.

---

## Getting Started

### Prerequisites

- An active menu with regular customer traffic
- This feature runs automatically — no setup required

### What Happens Behind the Scenes

1. During the day, MenuList tracks how customers interact with your menu
2. Overnight, the system analyzes the data
3. Item engagement scores are updated based on customer behavior
4. Recommendations (Decision Blocks) are refreshed with new insights
5. The system builds a deeper understanding of your menu over time

---

## How-To Guides

### How to know if intelligence is running

- If your menu has Decision Blocks (Most Popular, Quick Pick, Best Value), intelligence is active
- Blocks update daily — if recommendations change, the system is learning
- No dashboard or indicator needed — it runs silently

### How to check what changed

- Intelligence observations are internal and automatic
- You can see the effect through updated Decision Blocks on your menu
- Pin controls let you override any recommendation if you disagree

---

## Troubleshooting

### Recommendations haven't changed in days

**Why:** If customer traffic is low or consistent, the system's understanding stays stable.
**Fix:** This is normal. The system only changes when data supports it.

### I want to disable intelligence

**Fix:** Contact support. Intelligence is controlled via a feature flag.

---

## Tips

- More customer traffic = better understanding. Encourage QR code scanning.
- Don't worry about checking daily — the system handles everything
- Use pin controls if you want specific items always featured
- Understanding improves over time — the first week may be less accurate than week 4
