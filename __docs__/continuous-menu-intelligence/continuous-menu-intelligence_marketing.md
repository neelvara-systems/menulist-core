# Continuous Menu Intelligence — Communication Boundary

**Last verified:** July 16, 2026
**Status:** Internal-only capability; no standalone marketing claim.

CMI is a private observation/read-model layer. It is not an owner feature, customer feature, public menu surface, or independently marketable product benefit today.

## Allowed internal description

> MenuList maintains a private, bounded observation state from settled customer-menu interactions. It never changes canonical menu truth by itself.

## Public boundary

Do not market CMI as:

- an optimizing or self-improving menu;
- an AI-powered or smart ranking system;
- a system that knows orders, sales, ratings, reviews, inventory, or conversions;
- a feature that changes item visibility or menu order;
- a guarantee of better performance, higher revenue, or faster decisions; or
- a dashboard, insight feed, or owner control that does not exist.

If public copy discusses Featured Choices, use the separate Decision Intelligence claim boundary. Do not attribute Featured Choices to CMI output; the current public projection is computed directly from the shared compact analytics input and project catalog.
