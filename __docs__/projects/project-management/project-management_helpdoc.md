# Project Management — Help Documentation

## Quick Summary
Projects are your digital menus. Each project is a separate menu (e.g., "Food Menu", "Drinks Menu", "Desserts"). Here's how to create, manage, and organize them.

---

## How-To Guides

### How to create a new project (menu)
1. Go to **Projects** in your dashboard
2. Click **Create New Project**
3. Give it a name (e.g., "Food Menu", "Drinks", "Lunch Special")
4. Click **Create**
5. Your new project is ready — upload files or start adding items

### How to set a default project
1. Go to **Projects**
2. Find the project you want as default
3. Click the settings icon or **Set as Default**
4. This project will show when customers scan your QR code without a specific URL

> 💡 **Tip:** You can only have one default project. Customers scanning your base QR code see this one.

### How to rename a project
1. Go to **Projects**
2. Click the project name or settings
3. Type the new name
4. Click **Save**

> 💡 **Tip:** The project name becomes part of the URL (e.g., "Drinks" → yourstore.menulist.online/drinks)

### How to delete a project
1. Go to **Projects**
2. Find the project you want to remove
3. Click **Delete** (or the trash icon)
4. Confirm deletion

> 💡 **Tip:** Deleted projects can be recovered — they're archived, not permanently removed.

### How to manage multiple menus
1. Create separate projects for each menu type (Food, Drinks, Desserts)
2. Set one as **Default** (the main menu)
3. Each project gets its own URL: `yourstore.menulist.online/food-menu`
4. You can link between them or give customers separate QR codes

---

## Troubleshooting

### I can't find my project
**Fix:** Check if it was accidentally deleted. Contact support for recovery.

### My default project changed
**Fix:** Go to Projects and verify which one is marked as default. Only one can be default at a time.

---

## Tips
- 💡 Use clear, descriptive names — they appear in your URL
- 💡 One project per menu type (don't put food and drinks in the same project)
- 💡 Set your most important menu as the default
