# Description Generation - Marketing Boundary

**Status:** Historical marketing draft; not current sales, publication, or launch certification
**Last cross-check:** July 15, 2026

## Current Sales/Launch Boundary

The source-backed capability is: MenuList prepares menu descriptions from existing menu context. Bulk generation saves after the complete action succeeds; single-item generation remains a draft until Save. It can add first descriptions to eligible named items, refresh generated descriptions with an enhancement charge, protect manual copy, and support configured project languages.

Owner review remains necessary. Do not position generated copy as automatically owner-approved, guaranteed to cover every item, guaranteed to finish within a fixed time, or equivalent to a professional copywriter.

The phrase "menu description drafts for owner review before publishing" applies to the single-item draft path only. Bulk output is saved after complete success and should be described as awaiting prompt owner review. Owner-reviewed wording remains the operating expectation, not an automated guarantee.

## Approved capability language

- Prepare clear description drafts from existing menu context.
- Add a first description without using content credits.
- Refresh generated descriptions when the owner wants another version.
- Keep manual descriptions unchanged during refresh.
- Review single-item drafts before Save.
- See prepared/revised activity and credit use in Transactions.

## Do not claim

- fixed completion times;
- coverage for unnamed, policy-locked, manual, invalid, or provider-blocked items;
- identical quality across languages;
- owner approval without review;
- medical, allergen, nutrition, ranking, conversion, or sales outcomes;
- silent publishing of single-item drafts;
- a fixed bulk-refresh charge without knowing request/batch count.
