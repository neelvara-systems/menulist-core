# B2B View (JSON Editor) — Help Documentation

## Quick Summary
The B2B View shows your menu data in raw JSON format. This is a power-user tool for viewing and editing the underlying data structure directly.

---

## How-To Guides

### How to view your raw menu data
1. Go to **Projects** → select your project
2. Switch to the **B2B View** tab
3. See your complete menu data in JSON format
4. Use the expand/collapse controls to navigate

### How to edit data in JSON view
1. Open B2B View
2. Click on any field value to edit it
3. Make your changes
4. Click **Save**

> ⚠️ **Warning:** Editing raw JSON can break your menu if you change the structure. Use the regular Editor for normal changes.

---

## Troubleshooting

### JSON view is loading slowly
**Why:** Large menus with many items create large JSON documents.
**Fix:** Be patient. The view handles large documents but needs time to render.

---

## Tips
- 💡 Use this view for debugging — see exactly what data is stored
- 💡 For normal editing, use the visual Editor instead
- 💡 Copy JSON data if you need to share it with support
