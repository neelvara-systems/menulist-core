# Data Editor — Help Documentation

## Quick Summary
The Editor is where you manage your menu content — add items, change prices, upload photos, organize categories, and more. Changes you save here appear on your customer menu instantly.

---

## How-To Guides

### How to edit an item's price
1. Go to **Projects** → select your project
2. Find the item in the Editor
3. Click on the price field
4. Type the new price
5. Click **Save**

### How to add a new item
1. In the Editor, find the category where the item belongs
2. Click **Add Item** (or the + button)
3. Fill in: Name, Price, Description (optional), Image (optional)
4. Click **Save**

### How to mark an item as sold out
1. Find the item in the Editor
2. Toggle the **Available** switch to OFF
3. Click **Save**
4. The item appears faded on your customer menu

### How to reorder items
1. Click and hold an item
2. Drag it to the desired position
3. Release to drop
4. Click **Save**

### How to add or edit categories
1. Look for category headers in the Editor
2. Click a category name to edit it
3. Use **Add Category** to create a new one
4. Drag categories to reorder

### How to upload an item image
1. Click the image area on an item (or camera icon)
2. Choose: **Upload Photo** or **Generate Image**
3. Select or generate your image
4. Click **Save**

### How to delete an item
1. Find the item in the Editor
2. Click the delete/remove button
3. Confirm deletion
4. Click **Save**

> 💡 **Tip:** Deleted items can be recovered — they're archived, not permanently removed.

---

## Troubleshooting

### Changes not appearing on customer menu
**Fix:** Make sure you clicked **Save**. Changes appear within 60 seconds after saving.

### Editor is loading slowly
**Why:** Large menus with many images take longer to load.
**Fix:** Be patient on first load. Subsequent edits are faster.

### "Save failed" error
**Fix:**
1. Check your internet connection
2. Try saving again
3. If it persists, refresh the page — your recent edits may need to be re-entered

## Tips
- 💡 Save frequently — don't make 50 changes without saving
- 💡 Use categories to organize items (customers browse by category)
- 💡 Add images to your top items — they get more attention
- 💡 Mark items as "sold out" instead of deleting them
