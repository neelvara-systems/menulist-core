# Visual Profile Completion Help Doc

## What It Does

The Visual Profile card shows whether your public business profile has the basic photos customers expect to see.

It checks:

- main photo
- business photos
- menu or service photo, when available

## Where To Find It

Open:

`Business Settings -> Official Page`

On mobile, open the Official Page screen from the owner app.

## What The Status Means

`No action needed` means the current photo set is complete for the visible checks.

`Needs attention` means one or more photo areas are missing.

## How To Fix It

Use the existing photo controls on the Official Page screen:

- add or replace the main photo
- add business photos to the gallery
- add a photo to a menu or service page when that item is missing

## Notes

The card does not post photos anywhere else. It only checks the photo set used by your MenuList public page.
