## Quick Summary

GrowthOS shows a short list of public actions for the week. You can approve, edit, ignore, or export what is ready.

Current product decision: this helpdoc is not publish-ready. The weekly pack should return only if owner pilots prove that owners understand and use it without explanation.

## Before You Start

You need:

1. A business profile.
2. Current hours and contact details.
3. At least one menu item, service, offer, or approved business fact.
4. Photos or logo if you want visual assets.

## Open GrowthOS

1. Sign in.
2. Open GrowthOS.
3. Choose the business location.
4. Review this week's actions.

## Use a Freshness Action

1. Open an action such as missing hours, expired offer, or old photo.
2. Check the shown details.
3. Choose Approve, Edit, Ignore, or Export.
4. If the action changes public business information, GrowthOS sends you through the approved MenuList update flow.

## Generate a Weekly Growth Pack

1. Choose Generate Growth Pack.
2. Select the item, offer, or service to promote.
3. Add any short owner note if needed.
4. Generate the pack.
5. Review the outputs.
6. Copy, download, or export what you want to use.

## What GrowthOS Will Not Do

GrowthOS will not invent:

- prices
- discounts
- opening hours
- ingredients
- awards
- ratings
- delivery coverage
- booking availability

GrowthOS will not publish automatically in the first planned version.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No actions appear | Check that the business profile has menu/service data, hours, and photos. |
| An action looks wrong | Ignore it or edit it before approval. |
| A generated line is not accurate | Edit it or do not use it. GrowthOS should only use approved facts. |
| Export failed | Try again. If it still fails, copy the text manually. |
| Google posting is unavailable | Use the Google post draft manually. Direct posting is not part of the first plan. |
