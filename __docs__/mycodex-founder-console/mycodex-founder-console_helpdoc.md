# MyCodex Founder Console Operator Guide

## Open the console

1. Sign in to the MenuList owner app with the platform-owner Google account.
2. Open `/__mycodex/operations`.
3. Use Today for the current operating picture.
4. Open Products for MenuList or Answerlattice administration.
5. Open Systems for schedulers, extraction, notifications, and costs.
6. Open Documents to return to the private MyCodex reader.

## Status meaning

- Healthy: the current read completed and did not expose an attention condition.
- Attention: review is required.
- Unavailable: a current source failed or is not configured.
- Unknown: no current evidence is available.
- Stale: the visible result is older than the current refresh window.

## Mobile use

Install the existing MyCodex PWA from the owner-app path. Use the bottom navigation for daily work. Detailed tables can scroll horizontally inside their own panel.

## Offline use

When offline, MyCodex shows a private recovery screen. Reconnect before opening documents, refreshing data, or performing any operational action; documents and operational responses are not stored by the PWA worker.
