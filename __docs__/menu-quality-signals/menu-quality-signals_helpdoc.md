# Menu Quality Signals — Help Documentation

> **Version:** 1.0
> **Last Updated:** March 15, 2026
> **Audience:** Business owners (customers)

---

## Quick Summary

Menu Check shows simple suggestions to improve your menu — like adding descriptions, photos, prices, icons, or missing language text.

## How It Works

1. Open your **Dashboard**
2. Look at the **Menu Check** card
3. You'll see signals like:
   - "5 items missing descriptions" → Tap **Repair Menu**
   - "12 items missing images" → Tap **Review**
   - "All items have prices" ✓
4. When everything looks good, you'll see: **"No action needed"**

## What Each Signal Means

| Signal | What It Means | What to Do |
|--------|--------------|------------|
| Items missing descriptions | Some items don't have descriptions. Customers browse faster when descriptions explain each dish. | Use Repair Menu |
| Items missing images | Some items don't have images. Customers order more when they can see the food. | Review the items and add photos |
| Items missing prices | Some items don't show a price. | Open the editor and add prices |
| Items hidden from customers | Some items are not visible on the public menu. | Review the hidden items and show them again if needed |
| Prices need review | A price is much higher or lower than similar items in the same category. | Correct it, or mark it reviewed if the price is intentional |
| Category icons missing | Some categories do not have icons. | Use Repair Menu |
| Translations missing | Some menu text is incomplete in a selected menu language. | Use Repair Menu |

If prices are turned off in menu design, price-related checks are hidden. No action needed.

## Tips

- Start with Repair Menu when it appears. It fixes the parts MenuList can safely complete.
- Photos and prices still need owner review.
- You can always edit generated content in the editor
