# QR WhatsApp Experiments Website Guidance

**Status:** Internal
**Last Updated:** July 17, 2026

## Current Website Decision

Do not add public website claims for this feature until runtime exists.

The feature can be referenced internally in planning docs and future roadmap discussions, but the public site should not imply MenuList currently measures WhatsApp opt-ins from printed QR campaigns.

## Future Website Placement

When implemented, the best placement is likely:

- Assets / Print Kit feature section;
- WhatsApp-first landing page proof section;
- SMB campaign or local promotion use-case page;
- help article linked from Assets.

## Future Copy Direction

Use calm, factual copy:

```text
Test two printed QR campaign variants and see which one starts more useful WhatsApp conversations.
```

Avoid:

```text
Grow sales with AI QR automation.
```

## Required Proof Before Public Claim

Before public website copy:

- working owner UI;
- working tracked URL/landing flow;
- clear privacy/consent copy;
- dashboard screenshot or fictional demo screenshot clearly labeled;
- documented Firebase cost behavior;
- at least one verified local smoke test;
- no unsupported conversion or revenue-lift claim.

## Language Boundaries

- No "AI-powered".
- No "guaranteed".
- No "official WhatsApp".
- No "verified customers".
- No "no spam" unless policy/legal review approves exact context.
