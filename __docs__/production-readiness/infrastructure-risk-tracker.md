# Infrastructure Risk Tracker

**Purpose:** Centralized tracker for all infrastructure-level risks discovered during audits, production reviews, and implementation sessions. Cascade MUST update this file after every audit that identifies document size risks, storage growth issues, scaling concerns, or unbounded resource patterns.

**File:** `__docs__/production-readiness/infrastructure-risk-tracker.md`  
**Rule:** Rule 10.10 in `IDE_PROMPTS/MASTER-EXECUTION-PROMPT.md`  
**Last Updated:** July 26, 2026

---

## How This File Works

- After EVERY audit (Firebase cost, production, scalability, parity, system), Cascade checks for infrastructure-level risks
- Risks are categorized: **Runtime & Dependencies**, **Document Sizes**, **Storage Growth**, **Collection Growth**, **Query Performance**, **Cost Scaling**
- Each risk has: Description, Severity, Source Audit, Affected Files, Recommended Fix, Status
- Status: `⚠️ OPEN` → `🔧 FIX PLANNED` → `✅ RESOLVED`
- Resolved items stay in the file (with resolution date + fix description) for historical reference
