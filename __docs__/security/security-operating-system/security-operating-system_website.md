# Security Operating System - Website Boundary

> Website impact: none

Do not add SecurityOS to MenuList, Answerlattice, CampaignCue, Neelvara, or any other public website.

There is no:

- public route;
- product page;
- sitemap entry;
- SEO metadata;
- pricing or signup CTA;
- owner/customer dashboard entry;
- public help-center article;
- public API.

The root `SECURITY.md` is a repository policy, not a marketing page. If a public vulnerability intake channel is created later, it must be authorized separately and must not expose raw findings or private repository details.
