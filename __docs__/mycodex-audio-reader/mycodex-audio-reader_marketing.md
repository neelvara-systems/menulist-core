# MyCodex Audio Reader Marketing Notes

## Internal Positioning

MyCodex now supports hands-free documentation review using the device/browser voice engine.

## Value

- Helps with long specs and implementation docs.
- Useful on mobile and PWA installs.
- Avoids paid provider cost.
- Keeps document content inside the existing MyCodex page flow.

## Boundary

This is an internal reader convenience, not a public MenuList or Canonica capability.
