## What Is VisualMeta?

VisualMeta helps your team prepare product, menu, catalog, or listing content before it is used somewhere else.

You add source material, prepare content for each item, review the result, and export a Final Content Kit.

## What Is A Final Content Kit?

A Final Content Kit is the approved handoff package for a project.

It can include:

- approved images
- approved descriptions
- captions
- translations
- alt text
- usage notes
- source summary
- approval details
- export manifest

## Basic Workflow

1. Create a project.
2. Add source material.
3. Create content units for each item.
4. Prepare image or text candidates.
5. Review each candidate.
6. Approve the items that are ready.
7. Export the Final Content Kit.

## What Is A Content Unit?

A content unit is one item that needs prepared content.

Examples:

- one menu item
- one product
- one offer
- one listing
- one place

Each content unit keeps its source facts, candidate content, notes, and approval status together.

## Reviewing Content

When reviewing a content unit:

- check the source facts
- compare the source image and candidate image
- read the text variants
- check translations if present
- approve only when the content is accurate
- request changes if anything is wrong or unclear

Generated or edited content is not final until it is approved.

## Requesting Changes

Use request changes when:

- image does not match the item
- description changes a source fact
- translation is unclear
- required text is missing
- the wrong item is shown
- reviewer notes are not resolved

Add a short note so the next reviewer or editor knows what to fix.

## Exporting A Kit

You can export a kit after the included content units are approved.

The export includes files and a manifest so another team or tool can understand what was approved.

If something changes after export, create a new kit version instead of editing the old export.

## Export Package Formats

VisualMeta can use built-in package formats when export templates are enabled.

Examples:

- client handoff package
- menu item handoff package
- product catalog package
- translation package
- developer JSON package

These formats organize approved content. They do not approve content or send it into another system.

## Using MenuList As A Source

If MenuList import is enabled, VisualMeta can copy source snapshots from MenuList.

MenuList remains the live menu source. VisualMeta does not change prices, availability, hours, public menu pages, or live menu items.

If a MenuList source changes later, VisualMeta can create a new source snapshot and mark affected content as stale. Existing exported kits remain unchanged.

## What VisualMeta Does Not Do

VisualMeta does not:

- publish posts
- schedule content
- run ads
- update your website
- manage your live menu
- sync directly to Shopify, PIM, DAM, or catalog systems
- replace your product catalog
- approve content automatically

## Troubleshooting

### I cannot approve an item

Check whether the source snapshot is stale, required content is missing, or your account does not have reviewer permission.

### My export is not ready

Make sure every included content unit is approved and no source-stale warning is active.

### A download link expired

Open the export kit again and request a fresh download link if your account has access.

### A generated result changed a fact

Reject it and add a note. Source facts should not be changed during preparation.
