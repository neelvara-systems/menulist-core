## Notes

Legal docs are reference artifacts. Runtime, billing, product, and public-copy changes still need validation against current code and product doctrine.

The counsel packet is deliberately marked **not execution-ready**. It records
verified product facts, unresolved legal decisions, and the requested agreement
suite without inventing registered-entity details, governing terms, liability
allocations, or regulatory conclusions.
