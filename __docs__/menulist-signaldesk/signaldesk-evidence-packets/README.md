## What This Feature Covers

Evidence Packets preserve the facts, rejected facts, confidence, source rules, and decision snapshots behind each target action.

Every outreach action needs a reason and source trail. The corrected review places evidence packets and decision snapshots before templates, approval, and execution (`../../growth-engine/growth-engine_private-internal-tool-review-2026-06-23.md:219`).
