# SignalDesk Target Registry - Mobile Support Assessment

**Status:** Initial assessment
**Created:** June 23, 2026
**Mobile relevance decision:** No for normal registry work; read-only summary only.

## Admission Test

| Gate | Result | Reason |
| --- | --- | --- |
| Frequency | Fail | Target review is not urgent mobile work. |
| Speed | Fail | Correct review requires evidence/source context. |
| Touch | Fail | Dense target and contact tables are not thumb-friendly. |
| Value | Partial | Founder may need counts/status only. |

## Mobile Allowed

- target summary counts by state;
- held/suppressed count;
- import failure count;
- stale queue count.

## Mobile Blocked

- create target;
- upload/import CSV;
- reveal contact;
- change target state;
- merge duplicate;
- approve target;
- export target.

## Acceptance Criteria

- Mobile cannot reveal target PII.
- Mobile cannot mutate target records.
- Mobile can show counts only.
