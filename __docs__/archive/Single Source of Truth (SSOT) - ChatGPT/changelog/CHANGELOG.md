## Change Request Process

### For Documentation Updates

1. Submit written request
2. Engineering lead review
3. CEO approval (if policy change)
4. Update document
5. Update this changelog
6. Update version number

### For System Changes

**Allowed (Config Only):**

- Feature flag toggles
- Threshold adjustments
- Copy updates

**Forbidden (Until 2028):**

- New collections
- New decision surfaces
- New API patterns
- Architecture changes
