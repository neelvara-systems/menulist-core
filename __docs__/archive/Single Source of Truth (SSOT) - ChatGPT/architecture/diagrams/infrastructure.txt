╔══════════════════════════════════════════════════════════════════════════════╗
║                              DATA FLOW                                        ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. Customer → QR Scan → Analytics Events (Passive)
2. Nightly → CMI Scheduler → Process Analytics → Update Intelligence
3. CMI → Write → platformSummary/campaigns_{sId} (SSOT)
4. Owner → Today Tab → Read SSOT → Render Decisions
5. Screen → Read SSOT → Render Slides → Cache
6. Physical → Read SSOT → Generate PDF → Download
