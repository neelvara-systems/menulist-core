# Global Failure And Observability Help Boundary

If an error screen appears:

1. Choose **Try Again** for an in-place retry.
2. Choose **Refresh Page** only if retry does not recover the page.
3. Choose **Get Help** to open the maintained Help route.
4. If automatic reporting is configured, **Send diagnostic report** returns a
   report ID. Otherwise choose **Prepare support details** and copy the details
   into a support request.

These actions do not promise recovery of unsaved edits. Ordinary error recovery
does not clear browser caches.
