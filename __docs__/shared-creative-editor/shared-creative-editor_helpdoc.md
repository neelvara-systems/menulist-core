# Shared Creative Editor - Help Documentation

## Create An Asset

Open the editor from the product workspace.

In CampaignCue, use either:

1. Open a campaign pack.
2. Choose an output.
3. Open it in the editor.

Or:

1. Open Asset Library.
2. Choose **Create from scratch**.

You can also start from a local starter template inside the Templates panel, import an existing editor JSON file, import a compatible Fabric JSON file, add an image file, add an SVG file, or paste SVG markup.

## Edit Layers

- Select a layer on the canvas or in the layer list.
- Move it on the canvas.
- Change text, colors, size, or position in the properties panel.
- Change font, weight, style, underline, strike, line spacing, character spacing, text background, gradient, watermark, shadow, border, image filter, image outline, arrow style, or flip direction when the selected layer supports it.
- Use **Distribute X** or **Distribute Y** after selecting three or more layers to space them evenly.
- Edit polygon points in the layer panel when a custom shape needs exact corners.
- Lock a layer when it should not move.
- Hide a layer when you want to keep it but not show it.
- Move layers up or down to change what appears in front.

## Add Content

You can add:

- text and path text
- rectangle
- circle
- triangle, line, arrow, thin-tail arrow, polygon-style shapes, custom drawn polygons, and freehand drawing
- image URL
- image file or SVG
- QR code

Only use images the business has permission to use. If an image blocks PNG export, use SVG export or replace the image with an approved file. Use the image outline controls when a logo or product photo needs separation from the background.

## Download

Use:

- **Download PNG** for manual posting or handoff.
- **Download SVG** for editable vector handoff.
- **Download JSON** to keep a portable editor document.
- **Copy PNG** or **Copy base64** only when the browser supports clipboard access and the target workflow needs it.

The editor does not post directly to social media, WhatsApp, Google, or ad accounts. Use the downloaded file wherever the business already posts.

## Save To Product Library

Products may save an asset record after export. In CampaignCue, exported editor assets are registered in Asset Library with rights and campaign references when available.
