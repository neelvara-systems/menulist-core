# Shared Creative Editor - Help Documentation

## Create An Asset

Open the editor from the product workspace.

In CampaignCue, use either:

1. Open a campaign pack.
2. Choose an output.
3. Open it in the editor.

Or:

1. Open Asset Library.
2. Choose **Create from scratch**.

You can also start from a local starter template inside the Templates panel, import an existing editor JSON file, import a compatible Fabric JSON file, add a PNG, JPG, WebP, or GIF image file from the top toolbar, Images panel, or My Stuff panel, or add a direct PNG, JPG, WebP, or GIF image URL. Arbitrary SVG files and pasted SVG markup are not imported as editable runtime assets; extensionless owner-entered URLs, data URLs, JavaScript URLs, and raw source edits are rejected.

Use the campaign goal starters when you need a fast first draft for common jobs such as a weekend offer, new arrival, appointment reminder, or follow/share post. Starters use local editable layers, so the result can still be changed before download.

Use the Background panel to choose a common size such as square post, portrait post, story/status, flyer, menu screen, or QR table card. Use the safe-area guide button when text, logos, or QR codes need to stay away from the edge of the final image.

Use the Styles panel when the design looks unfinished. Apply a ready style, apply the connected brand style, or shuffle local styles. Styles update unlocked colors and fonts in the current design without calling an outside service.

Use the Text panel ready-made templates when you need campaign copy quickly. Templates such as sale, order now, free shipping, now open, book appointment, thank you, reviews, events, and hiring insert editable text layers, so each word can still be changed, moved, deleted, or restyled.

## Edit Layers

- Select a layer on the canvas, or open **Layers** to select it from the stack.
- Use the top toolbar that appears after selection for common text, image, shape, and position changes.
- Use the floating bar above the selected layer for quick actions such as ask, edit, color, style, flip, position, lock, duplicate, delete, and more controls.
- Move it on the canvas.
- Change text, image replacement, QR value/colors, colors, opacity, size, or position at the top of the properties panel.
- For selected text, use the local text actions to make it readable, shorten it, add a call to action, add contact text, center it, or bring it to the front.
- For selected text, use the business text chips to add product-provided facts such as business name, offer, contact, or destination without retyping them.
- Use the text checks to catch low contrast, small text, long copy, text near the edge, and missing customer action cues before download.
- For selected images, use Fill frame, Fit inside, Larger, or Behind text before opening advanced image controls.
- Change font, weight, style, underline, strike, line spacing, character spacing, text background, gradient, watermark, shadow, border, image filter, image outline, arrow style, or flip direction when the selected layer supports it.
- Use **Distribute X** or **Distribute Y** after selecting three or more layers to space them evenly.
- When several layers are selected, use the floating bar for group, distribute, duplicate, delete, or more controls.
- Open **Layers** when you need to hide, lock, reorder, or pick a layer that is hard to select on the canvas.
- Use the layer count, locked count, recent action label, and inline rename field in **Layers** when organizing a busy design.
- Drag a layer row in **Layers** to reorder what appears in front. Unlock the layer first if it cannot be dragged.
- Lock a layer when it should not move.
- Hide a layer when you want to keep it but not show it.
- Move layers up or down to change what appears in front.

## Keyboard Shortcuts

Open the keyboard button in the bottom canvas controls, or press `?`, to see the shortcut list.

Common desktop shortcuts include T for text, R for rectangle, C for circle, L for line, Q for QR, arrow keys to nudge, Command/Control + D to duplicate, Command/Control + G to group, Command/Control + Shift + G to ungroup, Command/Control + plus/minus to zoom, Command/Control + 0 to fit, Space to temporarily grab the canvas, and Escape to step back from popups, selection, and the left drawer until the full editor workspace is visible.

Shortcuts pause while you are typing in a field or directly editing text on the canvas. Escape still works from fields so you can back out of the editor UI without using the mouse.

## Add Content

You can add:

- text and path text
- text styles, ready-made text templates, and business text from the Text panel
- rectangle
- circle
- triangle, line, arrow, thin-tail arrow, polygon-style shapes, custom drawn polygons, and freehand drawing
- image URL
- image file
- QR code

Only use images the business has permission to use. If an image blocks PNG export, replace it with an approved file. Use Replace image file or the Images panel to change image sources; direct source editing is read-only for safety. Use the image outline controls when a logo or product photo needs separation from the background.

Use My Stuff to upload a local image, see recent session insertions, or reuse approved product assets. Use the drawer search to find templates, local tools, approved assets, text styles, ready-made text templates, project styles, Brand Kit items, and business text. Search does not connect to outside asset marketplaces.

## Brand Kit And Pages

Brand Kit can apply product-provided colors, logos, business name text, and brand font. It uses assets already connected by the product workspace.

Use **Add page** for another artboard, duplicate a page when a layout should be reused, and lock a page when it should not be edited. Downloads use the active page. JSON keeps the page list.

## Download

Use:

- **Review** to open the download check, fit the design, and focus on what needs attention before handoff.
- **Download** in the top toolbar when you need the current page as a PNG quickly.
- **Bundle** when you need common square, portrait, story/status, and flyer PNG handoff sizes.
- **Download PNG** for manual posting or handoff.
- **Download SVG** for editable vector handoff.
- **Download JSON** to keep a portable editor document.
- **Copy PNG** or **Copy base64** only when the browser supports clipboard access and the target workflow needs it.

Before download, the editor can flag empty text, poor contrast, small text, text too close to the edge, missing action text, unsafe image sources, and empty QR values. Fix the items shown in the check when possible. If the design is intentionally simple, repeat the download action to continue with the same warning set.

The editor keeps a browser-local recovery draft while you work. If a newer local draft exists when the editor opens again, restore it only when it is the version you want. This recovery draft does not replace the product workspace save/export flow.

The editor does not post directly to social media, WhatsApp, Google, or ad accounts. Use the downloaded file wherever the business already posts.

## Save To Product Library

Products may save an asset record after export. In CampaignCue, exported editor assets are registered in Asset Library with rights and campaign references when available.
