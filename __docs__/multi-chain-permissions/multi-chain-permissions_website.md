## Problem Statement

When store managers have full access, accidents happen — someone changes the logo, runs expensive image generation, or restructures the menu. You can't watch every location every day.

## Solution Statement

MenuList gives you two layers of control. Staff roles define what each person can do. Outlet policies define what each store can do. Both work together silently — no approval forms, no permission requests.

## Feature Benefits

### 1. Five Policy Categories

- **Override Control** — Decide if outlets can change prices, availability, descriptions, or images on inherited items
- **Local Content** — Allow or prevent outlets from adding their own items, categories, or projects
- **AI Features** — Gate expensive tools like image generation, description writing, and menu extraction
- **Branding** — Lock theme, layout, and logo changes to keep brand consistency
- **Language** — Control whether outlets can add languages from your language list

### 2. Three Staff Roles + Custom

- **Owner** — Full access to everything
- **Manager** — Day-to-day operations, no billing or branding
- **Staff** — Customer chat only
- **Custom Roles** — Create roles with exactly the permissions you need

### 3. Set Once, Forget

Configure outlet policies from the Locations page on desktop or mobile. They apply automatically to every user at that store. Changes take effect on next login.

### 4. Two Layers, One Result

A staff member can only do something if their role allows it AND the store's policy allows it. HQ staff are never restricted by outlet policies.
