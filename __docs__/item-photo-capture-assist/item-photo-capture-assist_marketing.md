# Item Photo Capture Assist Marketing

**Status:** Internal collateral only

## Elevator Pitch

MenuList gives owners a simple frame while they add an item photo, then handles the image preparation automatically.

## Feature Narrative

Restaurant owners do not need a photography workflow. They need item photos that are clear enough for customers to understand what they are ordering.

Item Photo Capture Assist keeps the action inside the existing item image flow. The owner can take a photo, use a simple frame, and save it without learning image sizes, crops, formats, or compression.

## Positioning

| Alternative | MenuList position |
| --- | --- |
| Professional food shoot | Useful for premium menus, but not required for everyday item updates. |
| Generic phone camera upload | Still available; capture assist gives a better starting frame. |
| Delivery-app photo rules | MenuList keeps the same source-photo discipline without adding a separate approval workflow. |
| AI image generation | Still available as a separate option for owners who do not have real photos. |

## Internal Talking Points

- This is not a new media product.
- This is not a photo score dashboard.
- This is not AI photo analysis.
- This is a low-friction intake layer before the existing image preparation system.

## Approved Language

Use:

- Item photo guide
- Ready to save
- Use another photo
- Photo is prepared automatically
- Existing upload still works

Avoid:

- Smart photos
- AI-powered photos
- Photo optimization score
- Professional studio workflow
- Conversion lift claims

## Packaging

This belongs with the existing menu image capabilities, not as a paid standalone module.
