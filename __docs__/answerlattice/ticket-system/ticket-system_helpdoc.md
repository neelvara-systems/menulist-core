# Create and Track an Answerlattice Support Request

> **Last verified:** July 19, 2026

## Create a request

1. Open **Support Tickets** in your Answerlattice workspace.
2. Choose the category and priority.
3. Enter a short subject and describe the issue.
4. Add a screenshot or supported document when it helps explain the problem.
5. Select **Send Request**.

The request appears in the same workspace with a reference ID and **Open** status.

## Send an unresolved widget question to support

When the embedded widget cannot resolve a question, select **Send to support**. Enter a reply email and optional detail. Answerlattice creates a request only after you submit the form. It preserves the eligible question and safe product context already recorded for that widget answer.

The confirmation reference means the request was created. It does not promise a response time.

## Continue the thread

Open the ticket to:

- review the initial request and later replies;
- see status changes;
- add a reply or attachment;
- submit satisfaction once the ticket is Resolved or Closed.

Statuses are:

- **Open**: received;
- **In Progress**: being reviewed;
- **Resolved**: a resolution was recorded;
- **Closed**: the thread is complete;
- **Re-Opened**: more review is required.

## Attachments

- Up to four files can be added in one action.
- Each file can be up to 10 MiB.
- Only supported image and document formats are accepted.
- Do not attach passwords, access tokens, recovery codes, payment-card data, or unnecessary personal information.

## Email

Answerlattice may send a confirmation, support-reply notice, or status-change notice when email delivery is configured. These messages are notifications only and say not to reply. Continue the conversation inside the ticket; reply-by-email is not supported.

Email failure does not remove or roll back a saved ticket.

## When the thread is full

A ticket keeps up to 50 message events and 25 status events. If it reaches a limit, create a new support request and reference the prior ticket. Answerlattice does not silently discard the retained history.

## Privacy

Tickets and attachments are private support records scoped to the workspace. Authorized support operators can access them. A ticket can inform a knowledge-review proposal, but its text is not automatically published or treated as an approved product answer.
