# Answerlattice Help Widget - Website Content

> **Updated:** July 18, 2026

## Website Job

Explain the widget as one governed delivery surface, not as Answerlattice's entire product category.

## Approved Summary

Place approved support inside your product. Answerlattice uses bounded page context, exact-origin controls, and an explicit asynchronous support request so a missing answer does not become an invented one or a dead end.

## Proof To Show

- an approved answer with source and scope;
- an unknown question entering fallback;
- the user creating a support request with the original question attached;
- the same answer updating after founder review;
- exact-origin and key-revocation controls;
- a page-aware workflow using allowlisted context.

## Content Rules

- Say `revoke a key`, not `delete a key`.
- Do not display a raw production key in screenshots.
- Do not show the legacy `/widget/{apiKey}` URL as the maintained install path.
- Do not present blocked routes as security enforcement.
- Do not publish numerical speed, cost, accuracy, coverage, or deflection claims until measured and verified.
- Keep Answerlattice positioned as governed answer infrastructure; the widget remains a surface that consumes that truth.
