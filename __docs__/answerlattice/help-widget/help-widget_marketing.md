# Answerlattice Help Widget - Marketing Boundary

> **Updated:** July 18, 2026

## Responsible Promise

Answerlattice can place approved, source-backed support inside a SaaS product, use bounded page context to select the applicable answer, and let an unresolved user create an asynchronous support request without re-entering the original question.

## Evidence-Backed Claims

- one maintained browser loader;
- exact-origin access control;
- approved-answer-first retrieval;
- bounded branding and route controls;
- source-backed responses where public citation policy permits;
- safe fallback when the runtime is denied or evidence is insufficient;
- explicit replay-safe support-request capture with server-derived context;
- key revocation with bounded cache propagation.

## Claims To Avoid

Do not claim:

- perfect accuracy;
- instant global key revocation;
- complete protection from the route blocklist;
- autonomous learning or automatic publication;
- support resolution without measured customer outcomes;
- a fixed installation time, latency, cost, deflection rate, or canonical hit rate without production evidence;
- that the iframe is sandboxed unless a verified sandbox contract is implemented.

## Product Boundary

The widget is a deployment surface for governed answers. It is not a generic chatbot builder, full help desk, unrestricted support agent, or arbitrary browser-control system.

Do not claim live support, guaranteed notification, a response-time SLA, automatic knowledge publication, or active automatic failure detection while its separate rollout flag remains off.
