# Use Weekly Digest

Weekly Digest summarizes the latest completed seven-day UTC support period.

## Read the Digest

1. Open **Support Control > Weekly Digest**.
2. Check the date range and freshness label.
3. Review the source-day warning before using comparisons.
4. Read the top repeated question, highlights, and recommended review work.
5. Open Support Board or Answer Tests only when that action is available to your role.

## Completeness

Conversation-volume and recorded-feedback comparisons show only when Answerlattice admitted seven source days for both the current and previous week. Otherwise they show **Not available**.

## Prepare the Latest Week

Users with support-management permission can select **Prepare latest week**. This rebuilds the deterministic completed-week projection from existing daily summaries. It does not call an AI model or modify approved answers.

## Warnings

- **Needs refresh:** the stored digest is no longer current.
- **Invalid timestamp:** the generation time is unexpectedly in the future.
- **Partial source days:** review the underlying screens before deciding.
- **No digest:** wait for settled analytics, refresh, or ask a permitted support manager to prepare it.

## Export

Export downloads the admitted digest as text. Missing comparisons remain **Not available** in the file.
