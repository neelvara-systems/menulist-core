# Scope Coverage Matrix Marketing Boundary

## Internal One-Liner

See whether your must-answer questions still resolve correctly for the right plan, role, product state, and version.

## Owner Value

- Replaces manual spot-checking across customer contexts.
- Makes missing or stale proof visible before support mistakes repeat.
- Separates an actual approved-answer gap from an intentionally different support route.
- Reuses the owner's existing critical questions instead of creating another setup task.

## Approved Claims

- `Review important answer coverage by plan, role, product state, and version.`
- `See current test evidence for the contexts you define.`
- `Open the exact test or approved answer that needs review.`

## Prohibited Claims

- `Complete coverage across every customer segment.`
- `Automatically finds every missing answer.`
- `Guarantees correct support.`
- `Maps every possible product state.`
- `Automatically fixes or publishes answers.`

## Competitive Boundary

This is not a generic permissions matrix or analytics heatmap. Its differentiation is the connection between owner-defined important questions, exact support context, governed answer retrieval, and current retained proof.

## Sales Demonstration

1. Open an active question that differs for Starter and Pro plans.
2. Show the explicit plan, role, state, and version columns.
3. Run the question through the existing canonical-only check.
4. Open the approved answer when review is required.
5. State that unspecified combinations are not inferred.
