# Native Helpdesk and Jira Connectors - Marketing Boundary

> **Publication Status:** HOLD
> **Last Updated:** 2026-07-20

Do not claim native Zendesk, Intercom, Freshdesk, Help Scout, or Jira connection, OAuth, synchronization, permission mirroring, automatic freshness, ticket write-back, or issue automation.

Safe current positioning:

- import selected helpdesk or issue-tracker exports;
- bring macros, canned replies, and repeated founder answers into review;
- treat ticket and issue history as evidence rather than approved truth;
- use Answerlattice alongside an existing helpdesk instead of replacing it.

Provider logos, setup CTAs, or integration-directory availability require a working provider runtime and release evidence.
