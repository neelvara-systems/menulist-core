# Native Helpdesk and Jira Connectors - Help

> **Last Updated:** 2026-07-20

Native Zendesk, Intercom, Freshdesk, Help Scout, and Jira connections are not currently available.

To use existing support material:

1. Export only the tickets, macros, canned replies, articles, or resolved issues needed for review.
2. Remove secrets and unrelated customer information.
3. Exclude attachments, internal notes, requester profiles, and unrelated conversation history.
4. Upload a supported file or paste selected repeated replies through Knowledge Intake.
5. Review the resulting evidence and drafts.
6. Approve product truth only through the existing governed answer workflow.

An imported ticket or issue can reveal a gap, defect, edge case, or reusable answer. It does not automatically establish the correct answer.
