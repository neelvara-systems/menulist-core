# Native Helpdesk and Jira Connectors - Mobile Support

> **Status:** No mobile runtime
> **Last Updated:** 2026-07-20

There is no desktop or mobile provider setup surface. Do not add mobile OAuth shortcuts, credential fields, provider pickers, or sync-status cards while the feature is absent.

The existing responsive Knowledge Intake and Repeated Reply Import workflows remain the supported path. If one provider is approved later, mobile must expose selected resource scope, permission state, last successful sync, partial failure, reconnect, disconnect, and deletion consequences with 44px actions and no hidden security tradeoffs.
