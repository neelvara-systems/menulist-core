# Autonomous Browser and Account-Changing Actions - Website Boundary

> **Publication Status:** No feature page
> **Last Updated:** 2026-07-20

Do not add an autonomous-agent, browser-control, action marketplace, or account-action page.

Guided Resolution copy must continue to say that Answerlattice highlights declared controls and waits for matching client-reported events without clicking controls or changing product data. It must not imply independent backend verification or guaranteed customer resolution. Demonstrations must show the user performing the action and must not simulate an unimplemented automated result.
