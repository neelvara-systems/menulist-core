# Autonomous Browser and Account-Changing Actions - Mobile Support

> **Status:** No autonomous mobile runtime
> **Last Updated:** 2026-07-20

Mobile guidance remains non-interactive and does not intercept taps. The user performs every product action. Route changes clear stale guidance, missing targets fall back to written instructions, and support handoff remains explicit.

Do not add mobile accessibility-service control, synthetic taps, hidden form submission, deep permission prompts, or action confirmation sheets for an unimplemented action system. Any future narrow assist action requires separate mobile authorization, confirmation, result, recovery, and accessibility review.
