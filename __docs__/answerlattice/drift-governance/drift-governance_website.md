# Drift Governance Website Boundary

Public website copy may describe Answerlattice as helping teams detect probable stale, conflicting, or deprecated answer dependencies and route them into review.

Recommended wording:

> See which approved answers may need review after a release, repeated support issue, scope conflict, or product deprecation.

Required qualification:

> Drift signals create review work. Answer changes remain human-approved.

Do not publish claims of continuous source monitoring, automatic correction, guaranteed freshness, complete conflict detection, or independently verified factual accuracy unless later production evidence supports them.
