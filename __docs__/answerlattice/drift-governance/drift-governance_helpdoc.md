# Drift Review Help

## What the queue means

A drift flag means Answerlattice found evidence that an approved answer should be reviewed. It does not mean the answer is definitely wrong, and it does not create a replacement automatically.

## Evaluate now

Use **Evaluate drift** to check current active answers against recent negative feedback, repeated ticket evidence, overlapping answer scopes, and deprecated product entities. Product-version drift is added when a release is activated.

## Review an answer

1. Open the drifted answer.
2. Read every listed drift reason.
3. Verify the current answer content against approved evidence.
4. Verify the plan, role, state, entities, and product-version applicability.
5. Edit through the normal Governance proposal flow if truth changed.
6. Revalidate only when the currently approved answer and scope are correct.
7. Confirm the review attestation and select **Confirm Review & Revalidate**.

## When not to clear drift

Do not clear drift because the answer looks plausible, because a ticket contains a reply, or because the source link still opens. Leave it in review and update the answer through Governance when evidence is incomplete or conflicting.

## Failure messages

If evaluation reports unavailable or over-cap data, no clean-health conclusion should be inferred. Retry after the stored-data or scale issue is resolved.
