# Set Up Your Answerlattice Workspace

> **Last Audited:** 2026-07-19

## Create the Workspace

1. Open `/get-started` and sign in with Google.
2. Enter the company and product details you can verify. Use an `http://` or `https://` product URL without a username or password in the address.
3. Select a monthly plan and checkout currency.
4. Select the first product areas where support matters.
5. Submit setup once and wait for the result.
6. Store the displayed widget key securely. It is shown only when first created.
7. Open checkout, then continue to the dashboard and Activation Command Center.

You do not need to connect every support source during this first session.

## If Setup Is Still Being Verified

Retry from the same signed-in account with the same company, plan, currency, and product details. Answerlattice preserves the exact attempt while it checks whether the payment provider created a subscription. Do not change the request or start a second account during this state.

If the page shows `ANSWERLATTICE_PROVIDER_CHECKOUT_EXPIRED`, the exact known provider checkout is no longer usable and its provisional scope has been deactivated. Retry once with the same setup details to start a fresh attempt. Do not reuse or share the old payment link.

## If the Workspace Was Already Created

Answerlattice may restore the workspace and checkout after a lost response. The original plaintext widget key cannot be displayed again. Rotate the key from the authenticated widget settings before installation.

## Payment Pending

Workspace creation does not mean payment has completed. Follow the provider checkout and wait for verified activation. Paid AI and Knowledge Intake remain unavailable until the subscription reaches an active or trialing entitlement state.

## Contact Support With

- signed-in email;
- company/product name;
- approximate time of the attempt;
- the fixed Answerlattice error code shown by the page.

Do not send payment credentials, API secrets, OAuth tokens, or the raw widget key. Support should inspect the attempt and provider notes before advising another submission.
