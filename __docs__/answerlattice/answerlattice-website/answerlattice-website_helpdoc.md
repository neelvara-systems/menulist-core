# AnswerLattice Public Website Help

> **Audience:** Prospective buyer or new founder account
> **Last audited:** July 19, 2026

## Evaluate Before Signup

1. Open **Demo** to inspect the seeded source-conflict, approval, release-drift, fallback, correction, and audit loop.
2. Open **Install** to check whether your app can add one script, exact allowed origins, blocked routes, and safe page context.
3. Open **Pricing** to compare Starter, Growth, and Studio monthly capacity in INR and USD.
4. Open **Trust and Data Handling**, **Security**, **Privacy**, and **Terms** before sending support material or starting checkout.

The demo is a deterministic sample. It does not use your product data, Firebase, or an AI provider and does not prove a customer outcome.

## Create A Workspace

1. Select a plan on Pricing or open **Create workspace**.
2. Sign in with Google.
3. Enter a company name.
4. Optionally add product name, HTTP(S) product URL, support email, and billing model.
5. Choose at least one main product page where users need help.
6. Choose INR or USD checkout.
7. Submit the form.
8. Save the one-time widget key if one is shown.
9. Complete the hosted payment checkout or open Billing.
10. Continue to Activation for knowledge, answer-test, and widget-install proof.

## Recovery

- If setup is already running, wait and retry the same request.
- If provider recovery is pending, wait a few minutes and retry with the same details.
- If checkout expired, submit the same details to create a new admitted checkout.
- If the account already owns a workspace, refresh and open the dashboard.
- If the form cannot complete, use `hello@answerlattice.com` without sending secrets or private customer data.

## Contact

The contact form accepts setup, demo, pricing, partnership, security, and other enquiries. Add only the context needed to evaluate the request. Do not include passwords, tokens, payment card data, customer ticket exports, or sensitive logs.

## Accessibility

All primary public actions use keyboard-reachable controls. The mobile navigation moves focus into the dialog, keeps Tab focus inside while open, closes with Escape, and restores focus to its trigger.
