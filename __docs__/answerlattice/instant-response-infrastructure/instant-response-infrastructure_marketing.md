# Instant Response Infrastructure Marketing Boundary

## Safe claim

Answerlattice can reuse reviewer-cleared canonical answers through an optional scope- and freshness-checked cache. Cache failure falls back to the normal governed retrieval path.

## Do not claim without measured evidence

- sub-20ms or sub-100ms answers;
- a 60% or other cache-hit rate;
- a fixed Firestore or AI-cost reduction;
- zero-cost infrastructure;
- zero downtime;
- zero stale-answer risk;
- that other vendors recompute every answer;
- that cache reuse proves customer resolution.

Commercial value should be measured as verified correct repeated answers with lower work/cost, not raw cache hits.
