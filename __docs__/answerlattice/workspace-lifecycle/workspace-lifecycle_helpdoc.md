# Workspace Closure and Data Erasure

Answerlattice workspace closure is a reviewed support process.

## Before requesting closure

1. Generate a Support Truth Export if you need a portable copy of approved entities, answers, help content, FAQs, surfaces, and releases.
2. Confirm whether an active subscription or pending payment exists.
3. Tell Answerlattice whether any legal, security, dispute, or investigation hold applies.
4. Identify the exact workspace to close.

Support Truth Export is not a complete account backup or legal data export.

## What closure does

- Stops workspace access.
- Revokes widget and Public API credentials.
- Removes hosted-help routing and compiled context files.
- Starts a 30-day recovery window.
- Preserves billing records and required operational evidence.

Closure does not automatically cancel, refund, or modify provider billing.

## Recovery

During the recovery window, contact Answerlattice and identify the exact workspace. Recovery restores workspace access only. API keys, widget keys, hosted-help routing, and compiled bundles must be recreated.

## Permanent erasure

After the recovery window, Answerlattice can start irreversible erasure after billing, export, legal-hold, and retained-evidence review. Erasure may require multiple bounded operator runs. Completion is recorded only after the deletion manifest is empty.
