# Workspace Lifecycle Mobile Support

## Admission decision

**Owner mobile UI:** Not admitted.

Workspace closure and erasure are rare, high-risk, and support-assisted. Adding a mobile destructive control would increase accidental deletion risk without improving a frequent founder workflow.

## Mobile behavior

- A closed workspace fails normal session and data access checks on desktop and mobile.
- Existing mobile surfaces show their normal inaccessible/forbidden recovery state.
- No mobile route, sheet, toggle, or destructive button is added.

## Future change gate

A mobile entry point requires verified demand, reauthentication, exact workspace confirmation, export and billing review, a recovery explanation, accessibility testing, and equivalent desktop/platform controls. It may request closure; it must not perform immediate erasure.
