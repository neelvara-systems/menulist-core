## Approved Public Copy

**Daily support brief for founders**

Answerlattice turns governed support evidence into a short daily plan: current answer risks, qualified support gaps, and the next review that actually needs you.

**Product page card**

Start with a daily support brief.

See up to four qualified current decisions, or a clear quiet state when complete evidence needs no action. It reads compact summaries, stays read-only, and routes you to the governed review screen.

## Boundary Copy

The brief is summary-only. It does not publish answers, close tickets, rewrite support truth, or create a separate task queue. It routes owners to the governed screen where review happens. A disabled-by-default internal rollout can prefill the existing Support Board form for selected launch/release work, but opening the form does not save a card and is not a public product claim.
