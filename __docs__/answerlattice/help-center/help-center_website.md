# MenuList Help Center — Website Content Decision

> **Version:** 1.1.0
> **Last Updated:** 2026-07-16
> **Audience:** Website, Product, SEO
> **Source:** Current route and content inventory

## Current Decision

MenuList has no dedicated public Help Center marketing route. The implemented surface is authenticated at `/help-center`; public website routes must not imply that dashboard support content or ticket history is publicly accessible.

Workspace knowledge base content is scoped to your tenant and store. This is a signed-in product boundary, not a public website claim or public content endpoint.

Item 30, the main website audit, owns any public capability mention. Until that audit proves a current placement and release evidence, this file is guidance rather than publish-ready landing-page copy.

## Approved Short Copy

> Help is available inside your MenuList dashboard. Browse published guidance, check updates, or send a support request that stays in your request history.

## Do Not Publish

- "Instant AI answers"
- "No hallucination"
- "All systems operational"
- guaranteed SLA or response times
- unsupported provider/model names or cache-hit percentages
- claims that a source-gated change is deployed

Any future website mention must link owners to the real sign-in/get-started path, use current MenuList legal routes, preserve product separation, and be checked against the current feature flags and production evidence.
