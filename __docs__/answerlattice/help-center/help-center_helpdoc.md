# MenuList Help Center — Owner Guide

> **Version:** 1.1.0
> **Last Updated:** 2026-07-16
> **Audience:** MenuList owners
> **Tone:** Calm, plain language

## Open Help

Choose **Help** in your MenuList dashboard. On a phone, open **More**, then **Help Center**.

You can use each option separately:

- **Knowledge Base** — browse published guidance;
- **Submit a Ticket** — send a request that needs follow-up;
- **Share Feedback** — tell us what is working or confusing;
- **Read FAQ** — check short answers to common questions;
- **Contact Us** — choose the right support path or use the fallback email;
- **What's New** — read published release notes.

## Ask a Support Question

1. Select the search box.
2. Enter one clear question.
3. Check the cited help articles before acting on important account or billing information.
4. Continue in Assistant mode for the same topic, or start a new question.

You may attach one supported screenshot to the question. If search is unavailable or an answer does not resolve the issue, browse the Knowledge Base or submit a ticket. Generated wording is a support aid, not a digitally verified record.

## Submit a Ticket

1. Choose **Submit a Ticket**.
2. Select a category and **Low**, **Normal**, or **High** priority.
3. Add a short subject and the details needed to reproduce the issue.
4. Optionally attach up to four supported images or documents. Each file must be 10 MB or smaller.
5. Choose **Send Request** once.

After MenuList confirms the request, it appears in your request history with a short display ID. Open it to see the current status or add a reply. Email notification delivery is separate from the saved request; use the Help Center history as the source of truth.

MenuList does not promise a response or resolution time in this screen. Priority helps describe urgency but is not a guaranteed SLA.

## Attachment Safety

Supported initial ticket files are JPEG, PNG, WebP, GIF, PDF, Word, JSON, XML, plain text, Markdown, CSV and HTML. Files are stored in the active support workspace. A saved attachment opens only when its link matches the configured support Storage bucket and the ticket's tenant/store path.

Do not attach passwords, payment card details, API keys or other secrets.

## Share Feedback

The feedback tab contains three independent forms: a general rating/comment, feature-usage feedback, and a feature request. Move to the form you need and submit that form. Your latest submission is shown below the forms when it can be loaded.

## Contact Fallback

Use `support@menulist.ai` when you cannot access the ticket surface. Partnership enquiries can use `partners@menulist.ai`. Do not send the same issue repeatedly through every path; keep follow-up in the saved ticket when possible.

## If Something Fails

- Search failure: use Knowledge Base, FAQ, tickets or email.
- Ticket history failure: retry after checking the active account/store; any cached history may remain visible.
- Attachment rejected: confirm the file type, 10 MB limit and four-file limit.
- Attachment will not open: do not copy an unknown URL; contact support with the ticket display ID.
- Mobile route looks wrong: return to **More**, then reopen **Help Center**.
