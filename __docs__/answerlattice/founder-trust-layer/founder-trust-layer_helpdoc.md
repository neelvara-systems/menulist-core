# Understanding Answer Evidence

Answer Evidence shows the latest complete 24-hour support-answer window.

- **Canonical coverage** shows how often an approved canonical answer was served.
- **Confirmed resolved** appears only when end users explicitly submit an outcome.
- **No escalation** shows how many recorded questions did not require the deterministic fallback classifier. It is not a resolution claim.
- **Drift** shows active answers that require review.
- **Entity answer coverage** shows how many active product entities have at least one active canonical answer.
- **Top review areas** prioritize support evidence. Weighted load is not an accuracy score.

If the panel is unavailable, the latest scheduler run may not have produced a complete source window. If it is stale, review scheduler diagnostics before relying on trend changes.

Use these metrics to choose what to review next. Use Answer Tests, citations, source review, and real customer outcomes to judge answer quality.
