# Answer Evidence Mobile Support

No separate mobile data path is required. Responsive owner surfaces use the same compact summary and parser as desktop.

Mobile presentation requirements:

- stack metric cards without horizontal clipping;
- keep labels explicit rather than shortening them to ambiguous scores;
- preserve stale, unavailable, and explicit-outcome states;
- keep table content horizontally scrollable when necessary;
- do not add a mobile-only raw-log query or listener.
