# Review Source Governance

> Availability: Controlled rollout

## Quick Summary

Source governance records whether imported material is suitable evidence for an approved answer. Reviewing a source does not publish it as product truth.

## Before You Start

- Open **Teach Answerlattice**.
- Select an intake job.
- Make sure you have permission to manage knowledge.
- Add at least one source.

## Review A Source

1. Open **Source governance**.
2. Select a source.
3. Choose the authority that best describes the source.
4. Choose its approval status.
5. Record who owns the source.
6. Select whether it is public, workspace private, or restricted.
7. Select whether it may be cited publicly, only internally, or not at all.
8. Add any product, plan, role, region, or version limits.
9. Add an effective date or next review date when known.
10. Link any already-reviewed source in the same intake that conflicts with it. Answerlattice records the conflict on both sources.
11. Add a short note when the decision needs context.
12. Save the review.

## Approval Status

| Status | Meaning |
| --- | --- |
| Unreviewed | No reviewer has accepted the source as evidence. |
| Approved | The source may support a review proposal. It is not automatically canonical truth. |
| Excluded | Do not use this source as evidence. |
| Superseded | A newer source has replaced it. |

## Resolve A Conflict

1. Open either linked source; the unresolved conflict appears on both.
2. Compare the source dates, owners, and applicability.
3. Confirm the correct product behavior with the source owner.
4. Update or exclude the outdated source.
5. Remove the conflict from either source only when the disagreement is resolved. Answerlattice clears the reciprocal link in the same save.
6. Review the canonical proposal again.

## Why A Proposal Cannot Be Accepted

A canonical proposal remains blocked when:

- one of its linked sources is unreviewed;
- one of its linked sources is excluded or superseded; or
- one of its linked sources still has a conflict link.

Review or replace the evidence, then return to the proposal.

## Privacy Tips

- Use `workspace private` or `restricted` for internal material.
- Do not mark a private ticket or customer conversation as publicly citable.
- Keep secrets and customer-specific data out of reviewer notes.
