# Early Access Mobile Support

## Public form

- Single-column fields on narrow screens.
- Minimum 44 px controls and clear labels.
- No horizontal scrolling.
- Confirmation remains readable without relying on artwork.

## Internal dashboard

- Summary cards wrap into a compact grid.
- Desktop table becomes applicant cards on narrow screens.
- Detail review uses a responsive drawer.
- Status and notes controls remain usable without hover.
- Filter zero-results stay plain; first-use no-data may use one contextual illustration.
