# Answerlattice Early Access

> Status: Local implementation and certification complete; hosted release evidence pending
> Scope: Public request intake and platform-admin review before general availability

Answerlattice public access is request-only while MenuList is the first live reference client. The public website remains explorable, but it does not create workspaces, subscriptions, checkout sessions, or payments.

The governed flow is:

`Website -> Request early access -> Confirmation -> Platform review -> Manual contact/invitation -> Existing private onboarding process`
