# Early Access Operator Guide

1. Open **Platform → Answerlattice Early Access** from the internal platform navigation. It is also linked from **Ops Control Room** beside the other platform monitors.
2. Review total and lifecycle counts.
3. Filter to **Pending** and open an applicant.
4. Review the product URL, stage, support area, expected questions, and optional feature idea.
5. Add private notes if needed.
6. Use **Email applicant** to contact the person from the operator's mail client.
7. Change the status only when the matching real-world action has happened.

Status guidance:

- `approved`: suitable for the next testing cohort;
- `invited`: a real private setup invitation was sent;
- `activated`: the applicant now has an approved workspace;
- `declined`: not a current fit;
- `withdrawn`: the applicant asked not to continue.

Changing a status does not create an account or send an email automatically.
