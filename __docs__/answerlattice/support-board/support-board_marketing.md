# Support Board Marketing

> **Last verified:** July 19, 2026

## Buyer Problem

Founder-led SaaS teams already have tickets, feedback, product changes, and unanswered questions. The problem is turning selected support friction into private, reviewable work without treating every ticket as approved truth or adopting a separate project-management system.

## Safe Position

Support Board is Answerlattice's private support-knowledge review queue. It lets authorized team members triage selected gaps, keep internal notes and status context, link governed answer proposals, and remove copied source customer details when they are no longer needed.

## Evidence-Backed Claims

- private tenant/workspace-scoped cards;
- manual cards plus rollout-gated bounded source preparation;
- deterministic deduplication for non-manual source cards;
- Needs Answer and review statuses;
- capped private notes and constrained status history;
- exact compact core counts after count-relevant changes once the live summary function is deployed;
- human-reviewed answer-proposal handoff;
- no automatic canonical publication.

## Claims Requiring External Evidence

- live exact counts in a target environment require deployed-function evidence;
- workload reduction, task completion, deflection, and support-time savings require real customer measurement;
- mobile usability requires authenticated hosted/device evidence;
- exhaustive ticket/signal coverage is not supported by bounded source windows.

## Do Not Position As

- a helpdesk replacement;
- a generic Kanban/project-management tool;
- an autonomous knowledge-approval system;
- a public roadmap;
- a complete audit/compliance ledger;
- a customer-data deletion system.

## Commercial Role

Support Board is a retention and knowledge-operations lever, not the acquisition wedge by itself. Its value is strongest after Answerlattice has answered or escalated real questions: it makes misses visible, keeps review work controlled, and connects selected friction to governed answer improvement.
