## 1. Commercial Boundary

This internal platform compatibility tool is **not** a standalone Answerlattice sales feature. The owner-facing product is Knowledge Intake and the governed answer lifecycle.

Internal one-line description:

> Import bounded source material into reviewable KB/FAQ drafts, resolve duplicates, and publish the approved set atomically.

## 2. Evidence-Backed Capabilities

| Point | Evidence |
|-------|---------|
| **Bounded multi-format input** | 1-8 files or synthetic pasted-text sources, 10 MiB each and 40 MiB total |
| **AI-structured output** | Categories → Sections → Articles with rich TipTap content |
| **Human review** | Platform review and duplicate reconciliation are required before publication |
| **Duplicate detection** | Reconciliation for articles similar to existing KB content |
| **Embedding readiness** | Current valid vectors are reused; changed articles are re-embedded before final publication |
| **Source lineage** | Generated articles retain the bounded job source-file list, not page-level fact attribution |
| **Real-time progress** | Live status updates during processing and publishing |
| **Atomic visibility** | Articles, generated FAQs, navigation, replacements, job status, and freshness switch together after embeddings succeed |
| **Reference-aware deletion** | Explicit job deletion reclaims unreferenced source objects and preserves shared paths |

## 3. Claims Not Allowed

- Do not call this the owner onboarding flow.
- Do not claim website crawling, YouTube/Google Drive connectors, page-level citations, automatic truth approval, or verified resolution.
- Do not publish fixed cost, accuracy, or competitor-comparison claims without current primary evidence.
- Do not position this compatibility tool as Answerlattice's category or moat.
