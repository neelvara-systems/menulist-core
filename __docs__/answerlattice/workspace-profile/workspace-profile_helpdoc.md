# Manage Product Details

Open **Settings** and use **Workspace Profile** to update:

- product name and product URL;
- support email;
- billing model context;
- the main pages users ask about;
- workspace timezone;
- the local time when the support day ends.

Select **Save**. Answerlattice updates its scheduler and marks runtime support context for refresh with the same save.

If the profile changed in another browser session, Answerlattice reloads the latest values. Review them before saving again; it will not silently overwrite the newer edit.

Use **Map Product Surfaces** for detailed route and workflow mapping. Use **Widget Management** for install keys, allowed origins, and widget behavior. Those are separate controls.

Product URLs must use HTTP or HTTPS and cannot contain embedded usernames or passwords.
