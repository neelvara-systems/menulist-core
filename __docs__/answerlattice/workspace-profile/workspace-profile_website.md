# Workspace Profile Website Boundary

No public-site change is required for Feature 29.

The profile is an authenticated operating control that supports existing claims about governed and current support context. It is not a standalone acquisition feature and should not become a homepage card.

If shown in a future product demo, demonstrate:

1. timezone or support-email edit;
2. successful governed save;
3. compiled context marked for refresh;
4. stale second-session edit rejected and reloaded.

Do not imply that saving the profile edits the customer's SaaS product, changes its billing plan, publishes unapproved knowledge, or configures every support integration.
