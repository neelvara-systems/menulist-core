# Ticket-to-Knowledge Loop - Mobile Support

> **Assessment:** Ticket transition supported where the shared ticket UI is available; governance review remains desktop-first

- Resolution signal behavior is shared across viewport sizes.
- Mobile must use the same persisted status transition, scope checks, lifecycle ID, signal emitter, and feature flag.
- No mobile-only ticket evidence or proposal format is allowed.
- The review queue may be viewed responsively, but approval must retain the full evidence, scope, source, and content checks.
- Do not introduce a quick-approve action that hides source or applicability review.
