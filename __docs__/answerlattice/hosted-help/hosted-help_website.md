# Hosted Help Center Website Claims

**Status:** Verified claim boundary  
**Last verified:** July 18, 2026

## Public website may state

- Publish reviewed help content on a supported custom help domain.
- Give customers one searchable place for documentation, FAQs, and release notes.
- Keep indexing off during setup.
- Use approved Knowledge Base publication state to control article visibility.
- Keep Answerlattice hosted-help domains separate from MenuList custom menu domains.

## Public website must qualify

- Supported hostnames use the current support-label routing contract.
- DNS activation depends on the client's provider and Vercel configuration.
- Search is client-side over loaded published content, not an AI correctness guarantee.
- Hosted Help does not expose private tickets, conversations, or internal notes.

## Public website must not state

- every custom hostname is supported;
- DNS is live immediately;
- Answerlattice guarantees search ranking or traffic;
- all workspace sources are public;
- hosted help replaces a documentation CMS or help desk;
- provider conflict means the domain belongs to the active workspace.

## Proof required before numerical claims

Use real customer evidence for setup time, content coverage, search usefulness, availability, indexation, support deflection, or resolution. Local source verification is not customer outcome evidence.
