# Repeated Reply Import — Website Impact

> **Status:** IMPLEMENTED  
> **Created:** 2026-06-06  
> **Audience:** Website/content maintainers

---

## Public Claim Boundary

After implementation, public copy may say:

- Answerlattice can start from repeated replies founders already send.
- Knowledge Intake can turn repeated replies into review drafts.
- Repeated replies can become FAQs or canonical answer proposals after approval.

Public copy must not say:

- Answerlattice reads your inbox.
- Answerlattice connects to Gmail, Outlook, Intercom, Zendesk, Freshdesk, Help Scout, or Jira for this feature.
- Answerlattice automatically publishes repeated replies.
- Answerlattice replaces a helpdesk queue.

---

## Recommended Website Updates

Narrow copy updates are allowed on:

- homepage Knowledge Intake mentions
- Knowledge Intake product page
- Resources Knowledge Intake description
- Get Started setup checklist
- Updates page entry

The copy should frame this as founder-owned source material, not support-agent reply templates.

---

## Copy Pattern

Use:

> Start with product links, docs, FAQs, support macros, and repeated replies you already send.

Avoid:

> Sync your support inbox and automate replies.
