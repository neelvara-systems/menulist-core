# Support Truth Export - Website Boundary

> **Current decision:** Do not create a standalone public feature page.

Support Truth Export is a trust and portability proof point, not an acquisition wedge. It may appear in security, governance, product-detail, or pricing comparison copy only when the wording stays within verified source behavior.

## Suitable Copy

"Authorized owners can download a private, bounded package of approved support truth. Operational conversations, embeddings, secrets, and raw audit history stay outside the file."

## Required Caveat

Describe it as governed support-truth portability. Do not label it a legal export, full backup, disaster-recovery system, or automatic migration.

## Proof Before Stronger Promotion

- hosted authenticated download;
- QA rule readback;
- one real customer review or migration workflow;
- measured package size/time;
- mobile and desktop browser verification.
