# Support Truth Change Control Website Boundary

## Permitted Website Copy

**Headline:** Keep support truth aligned with product changes.

**Supporting copy:** Before a versioned release is published, review directly linked approved answers, their evidence sources, mapped product surfaces, Answer Tests, and compiled delivery state in one owner-controlled flow.

**Proof points:**

- Direct answer and Answer Test impact review.
- Governed source freshness and recorded conflict visibility.
- Mapped page, workflow, article, FAQ, and changelog context.
- Source-version and compiled-context rebuild evidence.
- No automatic answer rewrite or publication.

## Placement

Use this as a compact capability inside the existing governance/release story. Do not create a separate product page, navigation category, or command-center claim.

## Publication Gate

Website copy may be expanded only after authenticated desktop and narrow-width QA confirms the release modal, source handoff, product-surface handoff, and compiled-context handoff. Until then, existing bounded "release impact" language remains the public claim.
