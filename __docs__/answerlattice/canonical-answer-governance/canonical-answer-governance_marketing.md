# Canonical Answer Governance Marketing Boundary

## Safe claims

- Answerlattice keeps important support answers as reviewed, version-aware canonical assets.
- Owners can scope an answer by product entity, plan, role, state, and version.
- Canonical answer changes pass through human review.
- Stale manual update proposals are rejected instead of silently overwriting newer approved truth.
- Approved changes carry audit snapshots and invalidate retrieval freshness state.

## Claims requiring broader evidence

- Accuracy or resolution-rate improvement
- Reduced ticket volume or founder hours
- Guaranteed current answers across every source
- Guaranteed absence of hallucinations
- Production latency, availability, or scale

These require real customer data, deployed runtime evidence, and the evaluation work audited in Features 2 and 9.

## Unsafe claims

- Automatically learns the correct answer
- Every answer is correct because it has citations
- Replaces a help desk or support team
- Publishes ticket-derived truth automatically
- Autonomous support employee

## Product boundary

Canonical answer governance is an ICP differentiator, answer-quality requirement, and trust/governance requirement. It is not a generic RAG administration screen or documentation CMS.
