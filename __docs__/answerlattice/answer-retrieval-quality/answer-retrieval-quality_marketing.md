# Answer Retrieval Quality Marketing Boundary

## Supported claims

- Answerlattice serves approved canonical answers before generative fallback.
- Answers can include reviewer-approved public source links.
- Plan, role, state, and product-version applicability can prevent an unsafe answer.
- Answerlattice can ask for required context or abstain when approved truth is unavailable.
- Answer Tests can check expected answer sources and citations before deployment.

## Claims that require customer proof

- accuracy percentage;
- resolution or deflection percentage;
- time saved;
- reduction in repeat contacts;
- guaranteed freshness;
- guaranteed hallucination prevention.

## Prohibited claims

- A citation guarantees correctness.
- Every connected source is approved truth.
- Answerlattice always answers.
- Low-confidence responses are automatically safe.
- Tickets or chats automatically update customer-facing truth.
- Cached answers are always high confidence.

Use `approved`, `source-backed`, `scope-aware`, `reviewed`, `clarifies`, and `abstains` only where the runtime contract is enabled and verified for the customer workspace.
