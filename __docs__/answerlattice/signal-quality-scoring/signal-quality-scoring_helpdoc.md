# Signal Evidence In The Review Queue

Knowledge proposals show the evidence that caused them to enter review:

- ticket count;
- negative chat count;
- escalation count when available;
- linked product entities;
- bounded source references used by the drafting workflow.

These counts show evidence volume, not whether a proposed answer is correct. Review the approved product sources and applicability before publishing any answer.

A ticket-resolution draft may show an `Extractor score`. It describes the extraction result only. It is not canonical-answer confidence and is not copied into canonical validation when the proposal is approved.

Older proposals created before this hardening may show zero escalations because that separate count was not stored.
