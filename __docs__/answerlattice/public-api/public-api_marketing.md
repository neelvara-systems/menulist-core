# Answerlattice Public API v1 - Marketing Boundary

> **Status:** Account-gated; not a general-availability lead feature

## Accurate Positioning

Use:

> Deliver the same approved Answerlattice answer to a trusted server-side support surface, with citations, applicability, safe fallback, and governed signal return.

The relevant customer value is consistent governed truth across surfaces, not API volume or a generic developer platform.

## Claims Allowed After Tenant Enablement

- Retrieve approved canonical answers from a trusted backend.
- Respect version, plan, role, state, and safe product context when supplied.
- Read active/beta public entity identifiers.
- Send bounded support-friction signals into human-governed review.
- Rotate or revoke one workspace key with an audit trail.
- Receive deterministic abstention/clarification instead of silent RAG fallback.

## Claims Not Allowed

- Generally available or self-serve Public API while the flag is account-gated.
- Guaranteed accuracy, completeness, freshness, resolution, or zero hallucination.
- Generic access to all Answerlattice data.
- Browser/mobile SDK support using the secret key.
- Direct ticket, knowledge, or account mutation.
- Automatic learning or automatic answer publication.
- Exactly-once delivery across an external consumer's full workflow.
- Citations prove an answer is correct.

## Sales Qualification

The feature is relevant only when the buyer has:

- an actual server-side surface that should consume governed answers;
- priority questions with approved coverage;
- a developer or operator who owns the integration and secret;
- a safe escalation path for abstentions; and
- willingness to evaluate verified resolutions, not merely API calls.

If the buyer only needs an in-product help surface, lead with the widget or Help Center. If they want a help-desk replacement, arbitrary actions, or a generic RAG API, the fit is poor.

## Proof to Collect Before Public Promotion

- time to first successful server request;
- critical evaluation-set pass rate;
- verified resolution and recontact outcomes;
- abstention/escalation correctness;
- key rotation/revocation drill result;
- latency and rate-limit behavior;
- owner maintenance burden;
- customer proof that one governed answer remained consistent across more than one surface.
