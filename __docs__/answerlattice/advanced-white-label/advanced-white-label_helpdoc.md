# Advanced White Label Help

Advanced white-label branding is not currently available to customers.

The hidden prototype stores a private profile only. It does not change the widget, hosted help center, knowledge base, emails, or public APIs.

For the live widget, use **Widget settings** to configure the supported accent color, header title, greeting, launcher behavior, and powered-by visibility. Do not expect values saved in the advanced branding prototype to appear in customer-facing support.
