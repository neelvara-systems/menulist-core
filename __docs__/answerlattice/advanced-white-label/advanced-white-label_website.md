# Advanced White Label Website Boundary

The public Answerlattice website must not present advanced white-label branding as shipped or available.

Website copy may describe the currently verified widget appearance controls. It must not imply that hosted help, knowledge pages, emails, APIs, or every support surface consume one customer brand profile.

Reconsider website coverage only after deployed surface parity, accessibility, cache propagation, entitlement, and customer evidence are verified.
