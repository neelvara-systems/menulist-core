## What Is This Feature?

**One-liner:** A dedicated Assets screen where owners choose one parent theme, then download a consistent set of branded files for tables, counters, entrances, feedback, campaigns, business cards, ID cards, postcards, product tags, and paper menus.

**Problem Solved:** SMB owners care deeply about printed table cards and menu files because customers see those before they talk to staff. The current files are functional, but the owner still needs stronger choice and polish without hiring a designer or learning a design tool.

**Solution:** MenuList provides one top-level Asset Theme across the print menu, cards, posters, stickers, and Menu Kit, backed by 47 governed theme families. Thirty-four themes are common and visible to every business. Five restaurant/food families are category-gated: Craft Kitchen, Ember House, Coastal Table, Sunday Table, and Counter Rush. Eight visually explicit families remain exact-type-gated for coffee, bakery, ice cream, salon/beauty, spa, and approved fitness businesses. Salon and Makeup Studio still receive five recommended light systems: Salon Atelier, Petal Studio, Pearl Veil, Terracotta Glow, and Glasshouse Garden. Spa and Spa Resort receive Ritual Sanctuary, Eucalyptus Retreat, Mineral Spring, Lotus Stillness, and Sunlit Ritual. Pearl Veil, Terracotta Glow, Glasshouse Garden, Mineral Spring, Lotus Stillness, and Sunlit Ritual are common because their artwork is not industry-specific; their original vertical context affects recommendation order only. The owner chooses only one menu or business theme. Every asset and the full ZIP inherit that selection. Non-menu printable assets remain generated from shared Creative Editor documents and keep the protected QR/link/frame contract.

Owners can save one **Business theme** and an optional **Menu theme**. Old per-asset style values are accepted only as migration input, deterministically folded into a parent theme, and never exposed as selectable styles. One-click output resolves the first eligible menu theme, eligible business theme, canonical business-type/category recommendation, then the governed common fallback. An ineligible historical value stays stored as a dormant preference but cannot render for the wrong business. Complete Menu Kit inherits that same resolved theme.

The Assets dashboard and each selected asset also expose one shared business-profile readiness contract. An authorized owner can complete reusable identity fields in place; Business Card additionally requests public contact fields. Saves use the canonical store/tenant Business Settings DAL and immediately regenerate the active preview. Assets never owns a duplicate business-profile document.

Branded QR action templates are handled inside this same governed catalog. The brand, CTA, short link, and visual frame can change by template; the QR pattern remains scan-safe and protected unless a future scan-regression suite admits constrained QR styling.

Context-first Product Tags inherit the active parent theme and now consume the same active localized item-option projection as the owner Share Card. The compact tag shows up to three real option names/prices and an exact remaining count; it keeps neutral `Options` wording because the saved data model does not classify choices as variants or add-ons.

## Architecture Overview

```text
Dashboard /assets
  -> current Brand Kit summary and coordinated multi-asset preview
      - every preview is a lazy, cached render of the canonical downloadable output
      - intrinsic page/card proportions are contained without cropping
  -> purpose groups: Place in your business / Promote & share / Business identity
  -> focused asset list plus one large preview and direct output actions
  -> searchable business-eligible 47-theme parent catalog in Change brand look
      - 34 common themes for every business
      - category-aware recommendation order across the common catalog
      - Craft Kitchen, Ember House, Coastal Table, Sunday Table, and Counter Rush for the canonical food category
      - Roastery Ledger for Cafe / Coffee Shop / Specialty Coffee Shop
      - Patisserie Conservatory for Cake Shop / Bakery
      - Gelateria Riviera for Ice Cream Shop
      - Salon Atelier, Petal Studio, Pearl Veil, Terracotta Glow, and Glasshouse Garden recommended for Salon / Makeup Studio
      - Ritual Sanctuary, Eucalyptus Retreat, Mineral Spring, Lotus Stillness, and Sunlit Ritual recommended for Spa / Spa Resort
      - Performance Circuit for the approved fitness types
  -> asset type sidebar; every asset inherits the active parent theme
  -> shared render input
  -> optional Saved designs registry for explicitly saved editor documents
  -> editor-backed output engine for non-menu print assets
      - CreativeEditorDocument template
      - locked QR/link source layers with four-module quiet zone
      - runtime-only MenuList attribution on export when policy requires it
      - PNG/PDF browser render
  -> existing specialized output engines
      - Print Menu PDF + image
      - Menu Kit ZIP
  -> style resolution from already-loaded store context
      - menu theme
      - business theme
      - exact business-type or category recommendation
      - governed fallback theme
```

The feature is a template orchestration layer. It uses Creative Editor documents for scan-first single assets and extended campaign assets, while Print Menu and complete Menu Kit keep their specialized pagination/ZIP renderers. It adds a stable catalog so templates are added by registering a new family and editor document layout, not by duplicating dashboard logic.
