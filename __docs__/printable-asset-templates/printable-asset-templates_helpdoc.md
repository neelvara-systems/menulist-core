# Printable Asset Templates - Help Documentation

## Quick Summary

Assets gives you downloadable files for tables, counters, entrances, feedback, and paper menus. Choose the file, choose a style, and download.

## Getting Started

### Before You Start

- Your menu should be published.
- Your store name should be correct.
- Add your logo and brand color in Business Profile for a better result.

## Open Assets

### Desktop

1. Open the dashboard.
2. Click **Assets** in the left menu.
3. Select the project if you have more than one menu.

### Mobile

1. Open the MenuList mobile app.
2. Tap **More**.
3. Tap **Assets**.

## Download a File

1. Select the file type, such as **Table Tent** or **Counter Sticker**.
2. Choose a style.
3. Review the image preview shown in the modal or sheet.
4. Tap **Download PDF** or **Download image**.

## Use One Style Across Files

1. Choose a style you like.
2. Select another file type.
3. Use the same style again before downloading.

The file will use your current store name, logo, color, and menu link.

## Which File Should I Use?

| File | Use It For |
| --- | --- |
| Print Menu | Paper menu or print shop handoff. |
| Table Tent | Tables where customers sit. |
| Single Table / Counter Card | Acrylic holders, counter stands, wall clips, or small display stands. |
| Counter Sticker | Billing counter, pickup counter, or reception desk. |
| Entrance Poster | Door, window, or host stand. |
| Feedback QR | Asking customers to leave private feedback. |
| Complete Menu Kit | Downloading everything together. |

## Troubleshooting

### My logo is not showing

Add your logo in Business Profile, then download again. If no logo is added, MenuList uses your business initials.

### The wrong menu is opening

Check the selected project at the top of the Assets screen.

### Feedback QR is unavailable

Turn on feedback first, then return to Assets.

### The file looks too plain

Try another style. Premium stores can also remove visible MenuList attribution.

## Tips

- Use matte paper for table cards and posters.
- Test the QR after printing.
- Keep the short link visible under the QR.
- Replace damaged cards quickly.
