# Assets Help

**Status:** Owner Help
**Last Updated:** June 21, 2026

## What It Does

Assets gives you the files customers scan, read, or carry from your business.

## Open Assets

### Desktop

1. Open MenuList.
2. Click **Assets** in the left menu.
3. Select the project if you have more than one.
4. Download the file you need.

### Mobile

1. Open the MenuList mobile app.
2. Tap **More**.
3. Tap **Assets**.
4. Download the file you need.

## Before You Print

Check **Print readiness** first. It shows whether the live link, logo, brand color, business name, and feedback QR are ready for printing.

Business cards and ID cards use saved phone, email, and address details when they are available. If a detail is missing, open **Customize in editor** on desktop and replace the placeholder before printing.

Open a template first. The preview appears before download, and the same template can be saved as PDF or image where supported.

On desktop, supported single assets also have **Customize in editor**. Use it for small copy or layout adjustments. The QR link stays protected.

Use **Printer Message** when sending files to a local printer. It copies the file specs and menu link so the printer knows what to print.

## Printing Tips

- Use matte finish where possible.
- Test one scan before printing in bulk.
- Keep the QR panel clean and flat.
- Replace damaged table cards quickly.
- You do not need to reprint for normal content or price changes because the QR opens the live page.
- Reprint when the logo, business name, brand color, domain, QR destination, or physical card condition changes.
