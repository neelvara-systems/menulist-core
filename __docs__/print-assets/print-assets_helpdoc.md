# Print Assets Help

**Status:** Owner Help
**Last Updated:** June 4, 2026

## What It Does

Print Assets gives you the files customers scan inside your business.

## Open Print Assets

### Desktop

1. Open **Use MenuList**.
2. Click **Print Assets**.
3. Select the project if you have more than one.
4. Download the file you need.

### Mobile

1. Open the MenuList mobile app.
2. Tap **More**.
3. Tap **Print Assets**.
4. Download the file you need.

## Before You Print

Check **Print readiness** first. It shows whether the live link, logo, brand color, business name, and feedback QR are ready for printing.

Use **Preview** on the file before sending it to a print shop. Preview shows the same generated output that Download will save.

Use **Printer Message** when sending files to a local printer. It copies the file specs and menu link so the printer knows what to print.

## Which File To Use

| File | Use |
| --- | --- |
| Table Tent | Tables where customers sit. |
| Single Table Card | Acrylic holders, wall clips, or counter stands. |
| Counter Sticker | Billing or pickup counter. |
| Entrance Poster | Door, window, or host stand. |
| Feedback QR | Exit or counter when feedback is enabled. |
| Print Menu | Full paper menu PDF. |
| Complete Menu Kit | Everything together in one ZIP. |

## Printing Tips

- Use matte finish where possible.
- Test one scan before printing in bulk.
- Keep the QR panel clean and flat.
- Replace damaged table cards quickly.
- You do not need to reprint for normal content or price changes because the QR opens the live page.
- Reprint when the logo, business name, brand color, domain, QR destination, or physical card condition changes.
