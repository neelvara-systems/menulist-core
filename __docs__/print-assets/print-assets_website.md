## FAQ

**Can I send these files to a local print shop?**
Yes. Print Assets produces standard PDF/PNG files and Menu Kit print instructions.

**Does this replace Print Menu?**
No. Print Menu is for the full printable menu PDF. Print Assets brings that together with table, counter, entrance, and feedback files.
