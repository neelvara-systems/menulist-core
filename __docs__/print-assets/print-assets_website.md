# Print Assets Website Copy

**Status:** Dedicated feature page updated for editor-backed print assets
**Last Updated:** June 15, 2026

## Placement Decision

Do not add a dedicated Print Assets homepage section. The homepage should keep print capability as a compact `Print files` output of the approved source.

The public website should expose the stronger owner value on the dedicated feature page `/features/print-ready-kit` because the implemented Assets workspace is now more than a simple Menu Kit bundle. It includes asset type selection, supported template family choice, image-first preview, editor-backed customization for supported desktop assets, separate PDF/image downloads, print-shop handoff, and reprint guidance.

For non-technical SMB owners, keep this capability practical and outcome-led:

- Homepage source map: keep the compact `Print files` output.
- Features page: explain paper menu PDF, table card, counter card, feedback QR, template choice, and printer handoff packet from the current approved menu.
- Features page brand group: explain branded table/counter/entrance/takeaway files with QR code and business color, ready for a local printer.
- Dedicated feature page: explain the Assets workflow as `pick asset -> choose supported template -> preview -> customize when needed -> download -> place/reprint`.
- Dedicated feature page visuals: show both the template-list/dashboard view and the editor customization view so owners understand the workflow before reading the details.
- Resources page: keep PDF-vs-digital education in `/resources/digital-menu-vs-pdf-menu`.

The dashboard and mobile PWA carry the full Assets workspace. The public website should not expose internal names such as `single-asset generation`, `renderer`, or implementation-specific print asset keys.

## FAQ

**Can I send these files to a local print shop?**
Yes. Print Assets produces standard PDF/PNG files and Menu Kit print instructions.

**Do all assets show nine templates?**
No. QR/display assets can expose the full governed style catalog. If an asset has fewer unique supported layouts, MenuList should show only real choices that produce different output.

**Does this replace Print Menu?**
No. Print Menu is for the full printable menu PDF. Print Assets brings that together with table, counter, entrance, and feedback files.

**Can I customize a template?**
Supported desktop assets can open in the editor so the owner can adjust practical details before export. The QR link and required placement rules remain protected.
