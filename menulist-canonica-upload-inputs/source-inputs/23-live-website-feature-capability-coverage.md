# MenuList Live Website Feature Capability Coverage

## Purpose

This source fills feature gaps found by checking the live MenuList website and comparing it with the earlier Canonica input set.

## Setup And Content

MenuList supports guided menu intake from:

- photo;
- PDF;
- existing menu link;
- typed menu;
- screenshot where the public flow supports it.

The live website also presents preparation tools for:

- generated item/menu images where plan and credits allow;
- customer-friendly descriptions prepared from menu data;
- translations from the same approved menu source;
- owner review before public use.

Canonica should answer these as owner-reviewed preparation features, not autonomous publishing.

## Publishing Surfaces

The feature page lists these customer surfaces:

- QR menu;
- Official Business Page;
- digital screen menu;
- web/sharing link;
- PDF export;
- business discovery attributes such as services, payment methods, dietary options, amenities, and custom attributes.

## Brand And Launch

MenuList includes brand/presentation support:

- theme builder with accent color, logo, layout, and preview across device sizes;
- instant launch kit after publishing;
- Menu Kit with table tents, counter stickers, entrance posters, delivery bag stickers, takeaway cards, QR, WhatsApp/Instagram assets, and placement guidance.

## After Publishing

The live website describes post-publish systems:

- featured section such as Featured choice, Quick choice, and Value choice;
- staff reference for current prices, availability, and item details;
- menu analytics;
- menu quality signals for missing descriptions, images, and prices.

## Operations

The live website lists operational features:

- special menu switching for festival/event/seasonal menus with automatic switch-back;
- temporary status banners such as Closed today or Opening late;
- multi-location management from a master menu with local override capability;
- menu presence checklist for Google, Instagram, WhatsApp, QR, screens, and related surfaces;
- customer message templates with menu link, address, and hours;
- Command Center bulk operations for pricing, availability, categories, and status;
- External Menu Sync for connected systems using signed full-menu snapshots after approved menu changes;
- mobile owner dashboard through phone browser or PWA;
- staff accounts and roles.

## Accuracy And Trust

The live website presents accuracy/trust systems:

- pricing integrity across MenuList surfaces;
- menu validation before save/publish;
- customer trust indicators such as location, open status, freshness date, search, sections, and clear actions;
- customer signals from public menu and Official Business Page.

## Analytics Boundary

The live website frames analytics as privacy-conscious, decision-ready signals:

- sessions, engaged sessions, intent sessions, and action sessions;
- item views, item taps, category interest, searches, no-result searches, unavailable-item taps;
- final actions such as calls, WhatsApp, directions, reservations, order clicks, shares, and official-page action taps.

It also says not to treat this as invasive personal tracking: no customer names, emails, payment details, scroll heatmaps, hover tracking, or exact GPS coordinates in that analytics flow.
